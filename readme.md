# はじめに
ここで公開している資料は、あちこちから収集してきた情報を集めてまとめたものです。 
場合によっては、誤解によるミスも含まれている可能性がありますので、
利用する際は、十分に確認してから利用するようにしてください。 
また、誤記に気が付いたら、お知らせいただけると幸いです。 
全く情報が無いよりは、調査のきっかけになる情報程度には何かあった方が良い、くらいの資料です。 

完璧な正確さを持った資料を用意できれば良いのですが、 
残念ながら、その精査のために膨大な時間、乃至、膨大な人員をかけられるほどの余裕はありません。 
なので、まずは 80点くらいの資料を提示して、誤記に気が付いた人に指摘していただいて、 
少しずつ 100%の完成度に近づけられたらと、思います。
