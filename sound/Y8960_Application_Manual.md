# 第1章 はじめに

## 1.1 本書について

本書は、MSX 用サウンドカートリッジ **Y8960 Cartridge** のプログラマーズマニュアルです。Y8960 は、MSX の音源として広く使われた Y8950（MSX-AUDIO）の後継という位置づけで開発された音源モジュールであり、Y8960 Cartridge は、その Y8960 を MSX のカートリッジスロットで利用するための開発用カートリッジです。

本書は、Y8960 を使って音楽・効果音を鳴らすアプリケーションやドライバを開発するソフトウェア開発者を対象に、レジスタ仕様やメモリマップなど、ハードウェア寄りの情報を中心に記述します。

対応機種は、MSX、MSX2、MSX2+、MSX turbo R です。

## 1.2 表記規則

本書では、次の表記を用います。

- アドレスや数値の 16 進表記には、末尾に `h` を付けます（例： `7FF0h`）。2 進数には末尾に `b` を付けることがあります。
- メモリ空間の 8KB 単位の区切りを **BANK**、SerialSRAM 側の 8KB 単位の実体を **BANK#n**（n はバンク番号）と呼びます。
- レジスタの読み書きは、R/W の欄で `RO`（読み出しのみ）、`WO`（書き込みのみ）、`RW`（読み書き）で示します。
- 「SSG1」「SSG2」は、内蔵する 2 つの SSG コアを区別する呼び名です。SSG1 がレジスタ番号 00h～0Fh、SSG2 が 10h～1Fh に対応します。

## 1.3 Y8960 の概要

Y8960 は、MSX で使われてきた複数の音源チップ相当の回路を 1 つに統合した、コンボカートリッジ構成の音源です。Y8950 の後継として、従来の MSX-AUDIO 互換機能を受け継ぎながら、収録音源の追加と、全音源のステレオ化を行いました。

ステレオ化は、すべての音源についてチャンネルごとにステレオ定位（パン）を指定できる方式です。各音源の出力はデジタルミキサーでミックスされ、ステレオで出力されます。

## 1.4 ブロック構成

Y8960 の確定構成は次の通りです。

| ブロック | 個数 | 内容 |
|---|---|---|
| SSG（YM2149 相当） | 2 | トーン 3ch＋ノイズ＋エンベロープを持つ PSG。チャンネル別パン付き。音楽用と効果音用に分けるなど、2 系統を独立に使える |
| OPLL-EX（YM2413 相当） | 1 | 9ch FM＋リズム。プリセット音色バンク切替とチャンネル別パンの拡張付き |
| OPL2（YM3812 相当） | 1 | 9ch FM＋リズム。タイマー 2 本と割り込みを内蔵。チャンネル別パンの拡張付き |
| ADPCM（ADPCM-B 相当） | 1 | OPL2 と同じレジスタマップ（Y8950 互換）で制御する ADPCM 再生回路。専用メモリ 256KB を使用 |
| OPM（YM2151 相当） | 1 | 8ch FM。チャンネルごとの L/R 出力指定を持つ |
| SCC | 1 | 波形メモリ音源 5ch（A～E）。メガROM バンク制御も兼ねる。チャンネル別パンの拡張付き |
| デジタルミキサー | 1 | 上記 5 系統（SSG / OPLL / OPL2＋ADPCM / SCC / OPM）のステレオ入力をミックスし、I2S で出力 |
| MSX-TIMER | 4 コア | インデックス／バリュー方式のタイマー。割り込みあり |
| System Controller | 1 | カートリッジの識別と Config ROM へのアクセスを提供する管理回路（I/O 40h～4Fh、デバイス ID = 02h） |
| SerialSRAM | 1 | 512KB。プログラム／データ用 256KB と ADPCM 専用 256KB |
| SPI ROM（Config ROM） | 1 | 起動時に内容の一部が SerialSRAM へコピーされる |

## 1.5 主な特長

- **SSG を 2 系統搭載**： 音楽用と効果音用に分けるなど、干渉しない使い分けができます。
- **OPLL-EX のプリセット音色バンク切替**： OPLL 内蔵のプリセット音色として、OPLL（YM2413）／OPLL-X（YM2423）／OPLL-P（YMF281）／VRC7 の 4 種の音色 ROM を搭載し、チャンネルごとにバンクを選べます（VRC7 バンクもバンクレジスタで選択できます）。
- **OPL2＋ADPCM は Y8950（MSX-AUDIO）互換のレジスタマップ**で制御でき、既存の MSX-AUDIO 向け資産を活用できます。
- **全音源ステレオ対応**： SSG、OPLL、OPL2、ADPCM、SCC はチャンネルごとのパン指定、OPM は YM2151 互換の L/R 出力指定を持ちます。ミキサーでは系統ごとの音量とマスター音量を調整できます。
- **Memory Mapped I/O による制御**： 通常の I/O ポートは電源投入直後は無効になっており、Memory Mapped I/O の手続きでブロックごとに有効化します（FM-PAC と同じ考え方の仕組みで、複数のカートリッジを個別に制御することも可能になります）。
- **MSX-TIMER を 4 コア内蔵**： 楽曲のテンポ管理などに使える、割り込み付きタイマーを備えます。

各ブロックの詳細は第 4 章～第 8 章、ミキサーは第 9 章を参照してください。

# 第2章 ハードウェア構成

## 2.1 カートリッジの構成

Y8960 Cartridge は、FPGA（TangPrimer25K）で Y8960 の全回路を実装した MSX 用カートリッジです。内部は大きく分けて、次の要素で構成されます。

- **音源ブロック群**： SSG×2、OPLL-EX、OPL2、ADPCM、OPM、SCC（第 1 章のブロック構成表を参照）
- **デジタルミキサー**： 5 系統のステレオ出力をミックスする時分割ミキサー
- **スロットインタフェース**： MSX スロット信号と内部バスの変換、アドレスデコード、I/O イネーブルの管理
- **SerialSRAM とその周辺**： 512KB のシリアル SRAM、CPU（SCC バンク）／ADPCM／初期化シーケンサの 3 者を調停するアービター、SCC バンク制御
- **SPI ROM（Config ROM）**： 起動用データを保持する SPI フラッシュ
- **System Controller**： カートリッジ識別と Config ROM アクセスの管理回路
- **I2S 出力**： ミキサー出力を外部へ出すデジタルオーディオ出力
- **クロック生成**： PLL と分周回路により、内部動作クロックを生成します

## 2.2 SerialSRAM の構成

搭載メモリは SerialSRAM 512KB です。8KB 単位で区切って BANK#0～#63 の番号を振ると、その役割は次の通りです。

| BANK# | 容量 | 役割 |
|---|---|---|
| #0～#15 | 128KB | BIOS ROM（起動時に Config ROM からコピーされる） |
| #16～#31 | 128KB | RAM（プログラム／データ用） |
| #32～#63 | 256KB | ADPCM 専用 RAM |

SerialSRAM のアドレス空間は最上位ビット（A18）で 2 つに分かれており、A18 = 0 が CPU から見える 256KB（BANK#0～#31）、A18 = 1 が ADPCM 専用の 256KB です。CPU からは、SCC バンク制御（第 3 章）を通して BANK#0～#31 の範囲だけが見えます。ADPCM 用メモリの内容は、ADPCM のレジスタ制御を通じて読み書きします（第 6 章）。

なお、BANK#32～#62 は CPU 空間からは BANK#0～#30 のミラーとして見え、BANK#63 は条件によって SCC レジスタバンクになります（第 3 章 3.5 節）。BANK#64 以降は未接続です。

## 2.3 起動時の動作

電源投入時（起動時）には、System Controller が初期化シーケンスを実行します。

1. Config ROM（SPI フラッシュ）の 7E0000h～7FFFFFh にある **128KB を、SerialSRAM の 00000h 番地からへコピー**します。これが BANK#0～#15 の BIOS ROM の内容になります。
2. コピー中は他のモジュールは停止し、/WAIT 信号によって MSX 本体も停止します。
3. コピーが終わるとカートリッジは通常動作に入ります。

また、電源投入直後およびリセット直後は、**音源ブロックの通常 I/O ポートはすべて無効**で、カートリッジはバスに応答しません。有効化の手続きは第 3 章 3.3 節を参照してください。リセット時の状態と推奨初期化シーケンスの詳細は第 10 章で扱います。

## 2.4 オーディオ出力

各音源の出力はデジタルミキサーでミックスされ、**24 ビット飽和処理**のうえ、I2S 形式で出力されます。I2S は 32 ビットスロット×2 チャンネルの構成です。

I2S のサンプリング周波数は約 94.4kHz です（PLL で生成する I2S クロック約 24.16MHz を分周。MCLK は未使用です）。詳細は第 9 章 9.4 節を参照してください。

ミキサーの系統別音量・パン・マスター音量の仕様は第 9 章を参照してください。

## 2.5 クロックとリセット

内部クロックは PLL で生成します（実装上は、入力クロック 28.63636MHz から 171.8MHz 系と約 24.16MHz 系を生成し、分周で 42.95MHz 系を作っています）。音源コアは原チップ相当のタイミングで動作するよう、このクロックから enable 信号を生成して駆動します。

リセットがかかると、I/O イネーブルはすべて無効（電源投入直後と同じ状態）に戻ります。

# 第3章 I/O マップとメモリーマップ

## 3.1 アクセス方法の概要

Y8960 Cartridge へのアクセスには、次の 3 つの経路があります。

1. **通常の I/O ポート**： 各音源ブロックに割り当てられた I/O アドレスを使う方法です。ただし電源投入直後はすべて無効で、Memory Mapped I/O の手続きで有効化するまでは使えません（3.3 節）。
2. **Memory Mapped I/O（MMIO）**： メモリアドレス 7FF0h～7FFFh に置かれた窓口です。音源レジスタへの直接アクセス、I/O ポートの有効化、ミキサーの音量設定を行います（3.4 節）。
3. **メモリ空間**： SCC がメガROM コントローラーを兼ねており、4000h～BFFFh のバンク切り替えと、SCC レジスタへのアクセスを提供します（3.5 節）。

## 3.2 I/O ポートマップ

| I/O アドレス | R/W | 内容 |
|---|---|---|
| 40h～4Fh | RW | System Controller（3.2.4 節） |
| 7Ch | WO | OPLL レジスタアドレス（MSX-MUSIC 互換） |
| 7Dh | WO | OPLL レジスタデータ |
| 7Eh | WO | OPM レジスタアドレス |
| 7Fh | RW | OPM レジスタデータ／ステータス |
| A0h | WO | SSG レジスタアドレス（ラッチ） |
| A1h | WO | SSG レジスタデータ書き込み（読み出すと FFh） |
| A2h | RO | SSG レジスタデータ読み出し |
| A3h | ― | 【要確認】 正式な扱いは未確認です。RTL 上は、読み出すと FFh が返り、書き込みは作用しません |
| B0h | RW | MSX-TIMER： インデックス（bit3～2 = コア選択、bit1～0 = レジスタ選択） |
| B1h | RW | MSX-TIMER： インデックスが指すレジスタの値 |
| B2h | RW | MSX-TIMER： 割り込みフラグ（読み出し／書き込みでクリア） |
| B3h | RW | MSX-TIMER： カウンタ読み出し（書き込みで対象コアを選択） |
| C0h | RW | OPL2 レジスタアドレス（書き込み）／ステータス読み出し（MSX-AUDIO 互換） |
| C1h | WO | OPL2 レジスタデータ |

ADPCM には独立した I/O ポートはなく、OPL2 のポート（C0h／C1h）から、Y8950（MSX-AUDIO）互換のレジスタマップで制御します。SCC にも I/O ポートはなく、メモリ空間だけに現れます。

### 3.2.1 SSG へのアクセス

SSG は、アドレスラッチ方式でアクセスします。

1. A0h にレジスタ番号を書きます。
2. A1h にデータを書くか、A2h からデータを読みます。

レジスタ番号と対象コアの対応は次の通りで、2 つのコアは 1 つのアドレスラッチを共有します。

| レジスタ番号 | 対象 |
|---|---|
| 00h～0Fh | SSG1 のレジスタ（YM2149 互換レジスタ） |
| 10h～1Fh | SSG2 のレジスタ（同上） |
| 20h～22h / 24h～26h | ゲイン調整レジスタ（SSG1 / SSG2） |
| 28h～2Ah / 2Ch～2Eh | パンレジスタ（SSG1 / SSG2） |

レジスタの詳細は第 4 章 4.3 節を参照してください。

### 3.2.2 OPLL / OPL2 / OPM へのアクセス

いずれも、アドレスポートにレジスタ番号を書き、データポートで値を読み書きする 2 ポート方式です。

- OPLL： 7Ch（アドレス）／7Dh（データ）。MSX-MUSIC と同じポートです。
- OPL2： C0h（アドレス）／C1h（データ）。MSX-AUDIO と同じポートで、ステータスの読み出しは C0h から行います。ADPCM のレジスタもこのマップに含まれます。
- OPM： 7Eh（アドレス）／7Fh（データ）。

### 3.2.3 MSX-TIMER へのアクセス

MSX-TIMER は 4 コアあり、すべて B0h～B3h の 1 組のポートでアクセスします。B0h にインデックス（bit3～2 でコア、bit1～0 でコア内レジスタを選択）を書き、B1h でそのレジスタの値を読み書きします。B2h は 4 コア分の割り込みフラグ（読み出し／書き込みでクリア）、B3h は選択中コアのカウンタ値の読み出しです。タイマーの仕様と割り込みについては第 10 章 10.2 節を参照してください。

### 3.2.4 System Controller

System Controller は I/O 40h～4Fh に接続された管理回路で、カートリッジの識別と Config ROM への読み書きを提供します。音源とは独立に、電源投入直後からアクセスできます。

| I/O アドレス | 内容 |
|---|---|
| 40h | イネーブラ。80h を書くと有効化される。有効化後は読み出すと 7Fh（80h の全ビット反転）が返り、プログラムはこれで System Controller の存在を認識する。有効化されるまで、40h～4Fh の読み出しには応答しない |
| 41h | デバイスセレクト。デバイス ID を書く。Y8960 Cartridge の ID は **02h**。自 ID が書かれた場合のみ、読み出しにその反転値（FDh）を返す。他の ID の場合は応答しない（他デバイスとのバス競合回避のため） |
| 42h | ファンクションセレクト。01h = Config ROM Reader/Writer。正しく選択された状態で読み出すと FEh が返る |
| 43h～45h | Config ROM アドレス（下位／中位／最上位 8 ビット） |
| 46h | コマンド（00h = 読み出し、01h = 書き込み、02h = セクター消去（64KB 単位）、03h = チップ消去、04h = ステータス読み出し。読み出すと FFh） |
| 47h | データ。読み出し／ステータスの結果は、コマンド完了後にこのポートから読む。ステータスの bit0 が BUSY |
| 48h～4Fh | 予約。読み書きに応答しない |

コマンド実行中（数 μs）は System Controller への I/O アクセスは受け付けられません（WAIT は出ません）。46h にコマンドを書いた後は、40h が 7Fh を返すようになるまで読み出しを繰り返してから、次のアクセスを行ってください。

## 3.3 電源投入時の状態と I/O ポートの有効化

電源投入直後およびリセット直後は、**音源ブロックの通常 I/O ポートはすべて無効**で、カートリッジはそれらのアドレスに応答しません。他のサウンドデバイスと競合しないための仕様で、Panasonic FM-PAC と同じ考え方に基づいています。

有効化は、Memory Mapped I/O の **I/O Enabler1（7FF6h）** と **I/O Enabler2（7FFFh）** への書き込みで、ブロックごとに行います。

| アドレス | ビット | 有効化するブロック |
|---|---|---|
| 7FF6h（Enabler1） | b0 | OPLL |
| 7FFFh（Enabler2） | b0 | OPL2（＋ADPCM） |
| | b1 | SSG |
| | b2 | OPM |
| | b7 | MSX-TIMER |

ビットに 1 を書くと有効、0 を書くと無効に戻ります。Enabler2 は読み出しも可能で、現在の設定を読み戻せます。

![7FF6h（I/O Enabler1）のビット配置](images/bf_enabler1.png)

![7FFFh（I/O Enabler2）のビット配置](images/bf_enabler2.png)

なお、MMIO 自体はカートリッジのメモリ空間に対するアクセスなので、複数の Y8960 Cartridge を装着した場合でも、カートリッジごとに個別に有効化・制御できます（有効化されていないカートリッジの I/O ポートは無効のままなので、I/O 空間でも競合しません）。

## 3.4 Memory Mapped I/O（7FF0h～7FFFh）

MMIO は、メモリアドレス 7FF0h～7FFFh の 16 バイトの窓口です。7FFFh を除いて書き込み専用です。この窓口が使えるのは、**RAM モード = 0 のとき、または BANK1 に ROM バンク（BANK#0～#15）が出現しているとき**に限ります（3.5 節）。

| アドレス | R/W | 内容 |
|---|---|---|
| 7FF0h | WO | SSG レジスタアドレス |
| 7FF1h | WO | SSG レジスタデータ書き込み |
| 7FF2h | WO | OPL2 レジスタアドレス |
| 7FF3h | WO | OPL2 レジスタデータ |
| 7FF4h | WO | OPLL レジスタアドレス |
| 7FF5h | WO | OPLL レジスタデータ |
| 7FF6h | WO | I/O Enabler1（b0 = OPLL） |
| 7FF7h | WO | SSG 音量 |
| 7FF8h | WO | OPLL 音量 |
| 7FF9h | WO | OPL2 音量 |
| 7FFAh | WO | SCC 音量 |
| 7FFBh | WO | OPM レジスタアドレス |
| 7FFCh | WO | OPM レジスタデータ |
| 7FFDh | WO | OPM 音量 |
| 7FFEh | WO | マスター音量 |
| 7FFFh | RW | I/O Enabler2（b7 = TIMER、b2 = OPM、b1 = SSG、b0 = OPL2） |

音量はすべて 8 ビット値で、0 = OFF、128 = MAX です。ミキサーの詳細は第 9 章を参照してください。

MMIO 経由のレジスタアクセスは、通常 I/O ポートの有効／無効とは無関係に、いつでも使えます。ドライバの初期化時など、I/O ポートを有効化する前に音源を初期化したい場合に便利です。

## 3.5 メモリーマップとバンク制御

### 3.5.1 バンク構成

CPU のメモリ空間 4000h～BFFFh は、8KB ごとに 4 つのバンクに分かれています。

| CPU アドレス | バンク名 |
|---|---|
| 4000h～5FFFh | BANK0 |
| 6000h～7FFFh | BANK1 |
| 8000h～9FFFh | BANK2 |
| A000h～BFFFh | BANK3 |

各バンクにはバンクレジスタがあり、値 n を書き込むと SerialSRAM の BANK#n がそのバンクに出現します。BANK#n の内容は第 2 章 2.2 節の通り（#0～#15 = ROM、#16～#31 = RAM）で、バンク番号の上位側は次のように扱われます。

| バンク番号 | 扱い |
|---|---|
| #32～#62 | BANK#0～#30 のミラー |
| #63 | 条件を満たすと SCC レジスタバンク（3.5.3 節）。それ以外の範囲では未接続（ROM は出現しない） |
| #64～#255 | バンクレジスタは 6 ビットのため上位 2 ビットは切り捨てられ、#0～#63 と同じ扱いになる（たとえば #127 は #63 として扱われる） |

バンクレジスタは書き込み専用で、値を読み戻すことはできません。バンクレジスタのアドレスを読み出すと、そのアドレスに出現している SerialSRAM の内容が返ります。

**BANK0 は読み出し専用**です。RAM バンク（#16～#31）を出現させても、BANK0 への書き込みは SRAM に届きません（後述の RAM モードレジスタへの書き込みを除きます）。

### 3.5.2 RAM モードとバンクレジスタの配置

バンクレジスタの配置は、RAM モード（互換モード／RAM モード）によって変わります。電源投入時は RAM モード = 0（互換モード）です。

**RAM モード = 0（互換モード）** のバンクレジスタ：

| アドレス | 内容 |
|---|---|
| 5000h～57FFh | BANK0 バンクレジスタ |
| 7000h～77FFh | BANK1 バンクレジスタ |
| 9000h～97FFh | BANK2 バンクレジスタ |
| B000h～B7FFh | BANK3 バンクレジスタ |

**RAM モード = 1** への切り替えは、アドレス **4XFBh（X = 8～F）の b0** に 1 を書いて行います。RAM モードでは次のように変わります。

| アドレス | 内容 |
|---|---|
| 4XFBh | BANK モードレジスタ（b0： 0 = 互換モード、1 = RAM モード）。常に出現している |
| 4XFCh | BANK0 バンクレジスタ |
| 4XFDh | BANK1 バンクレジスタ |
| 4XFEh | BANK2 バンクレジスタ |
| 4XFFh | BANK3 バンクレジスタ |

RAM モードでは、BANK1～BANK3 への書き込みが SRAM まで届くようになり、BANK1 に SCC レジスタバンクを出現させることもできるようになります。なお、RAM モードやバンクレジスタへの書き込み自体は、出現中の BANK# の内容には書き込まれません。

### 3.5.3 SCC レジスタバンク

BANK#63 を出現させると、そのバンクは SCC レジスタバンクになります。出現位置は次のとおりです。

| 条件 | SCC レジスタの出現アドレス |
|---|---|
| BANK2 に BANK#63（RAM モードによらない） | 9800h～9FFFh（アドレス表は 9xxxh） |
| RAM モード = 1 で BANK1 に BANK#63 | 7800h～7FFFh（アドレス表は 7xxxh） |

BANK#63 が出現しているバンクでは、SCC レジスタの窓（上表の範囲）以外のアドレスにも ROM は出現せず、未接続になります。

レジスタ配置の概要（9xxxh の場合。7xxxh の場合は上位桁が 7 になります）：

| アドレス | R/W | 内容 |
|---|---|---|
| 9800h～981Fh | RW | Ch.A 波形メモリ（32 バイト） |
| 9820h～983Fh | RW | Ch.B 波形メモリ |
| 9840h～985Fh | RW | Ch.C 波形メモリ |
| 9860h～987Fh | RW | Ch.D/E 波形メモリ |
| 9880h～9889h | WO | 各チャンネルの周波数レジスタ |
| 988Ah～988Eh | WO | 各チャンネルの音量レジスタ |
| 988Fh | WO | 出力スイッチ |
| 9890h～989Fh | WO | 9880h～988Fh のミラー |
| 98E0h～98FFh | WO | モードレジスタ（実体は 1 バイト） |
| 9900h～9904h | WO | Ch.A～E のステレオ定位（パン）。1 = 左端、128 = 中央、255 = 右端。デフォルト 128 |
| 9905h～9FFFh | ― | 未使用（アクセス禁止。将来予約） |

周波数・音量などの書き込み専用レジスタは、読み出しても値が返ることは保証されません。SCC レジスタの詳細は第 7 章 7.3 節を参照してください。

# 第4章 SSG

## 4.1 概要

Y8960 には、YM2149（AY-3-8910 互換）相当の SSG コアが **2 個**搭載されている。本書では 1 個目を **SSG1**、2 個目を **SSG2** と呼ぶ。各コアはトーン 3 チャンネル（A / B / C）、ノイズジェネレータ 1 系統、エンベロープジェネレータ 1 系統を持ち、レジスタ構成と基本動作は YM2149 と互換である。

2 個のコアは常時同時に動作し、出力は加算されてミキサーの SSG 入力へ送られる。2 コア体制は、片方を音楽用、もう片方を効果音用に使うといった用途を想定したものである。どちらのコアをどちらの用途に割り当てるかはソフトウェアの自由であり、ハードウェア上の区別はない。ただし後述のとおり、レジスタの読み出しができるのは SSG2 側だけである点に注意すること。

Y8960 での拡張は次の 2 点である。

- **チャンネル別ステレオ定位（パン）**： A / B / C の各チャンネルに 8 ビットのパンを指定でき、左右の定位をチャンネルごとに変えられる（4.6 節）。
- **チャンネル別ゲイン**： 各チャンネルの出力レベルを 8 ビットで調整できる（4.6 節）。

## 4.2 アクセス方法

### 4.2.1 I/O ポート

SSG へは I/O ポート A0h〜A3h でアクセスする。2 コアは 1 つのレジスタアドレス空間を共有しており（4.3 節）、ポートの役割は次のとおりである。

| ポート | R/W | 機能 |
|---|---|---|
| A0h | W | レジスタアドレスの指定 |
| A1h | W | レジスタへの書き込み（読み出すと FFh が返る） |
| A2h | R | レジスタの読み出し |
| A3h | − | 予備。アクセスしても何も動作しない（読み出しは FFh） |

書き込みの手順は、A0h にレジスタアドレスを書き、続いて A1h にデータを書く。読み出しは、A0h にレジスタアドレスを書いた後、A2h を読む。

なお、電源投入直後は SSG の I/O ポートは無効化されている。使用するには I/O イネーブラ（MMIO 7FFFh の SSG ビット）を 1 にして有効化する必要がある（第 3 章参照）。

### 4.2.2 メモリマップド I/O（ミラー）

同じレジスタアクセスは、メモリマップド I/O 7FF0h / 7FF1h からも行える。

| アドレス | R/W | 機能 |
|---|---|---|
| 7FF0h | W | レジスタアドレスの指定（A0h と同じ） |
| 7FF1h | W | レジスタへの書き込み（A1h と同じ） |

ミラー側は書き込み専用であり、読み出しはできない。ミラーが利用できるメモリ状態の条件については第 3 章を参照すること。

## 4.3 レジスタマップ

レジスタアドレスは 6 ビットで、1 つの空間に SSG1 / SSG2 の基本レジスタと拡張レジスタが並んでいる。

| アドレス | 対象 | 内容 |
|---|---|---|
| 00h〜0Fh | SSG1 | 基本レジスタ（表 4.2） |
| 10h〜1Fh | SSG2 | 基本レジスタ（表 4.2 と同構成） |
| 20h〜22h | SSG1 | チャンネル別ゲイン A / B / C（4.6 節） |
| 23h | − | 未接続 |
| 24h〜26h | SSG2 | チャンネル別ゲイン A / B / C（4.6 節） |
| 27h | − | 未接続 |
| 28h〜2Ah | SSG1 | チャンネル別パン A / B / C（4.6 節） |
| 2Bh | − | 未接続 |
| 2Ch〜2Eh | SSG2 | チャンネル別パン A / B / C（4.6 節） |
| 2Fh | − | 未接続 |
| 30h〜3Fh | − | 未接続 |

レジスタアドレスは下位 6 ビットで解釈されるため、40h〜FFh を指定すると 00h〜3Fh のミラーとして扱われます。たとえば 50h を指定すると 10h（SSG2 の R#0）にアクセスします。

**読み出しの可否**： 読み出し（A2h）ができるのは **SSG2 側のレジスタ（10h〜1Fh、24h〜26h、2Ch〜2Eh）のみ** で、SSG1 側のレジスタはすべて書き込み専用である。SSG1 側のアドレスを指定して読み出すと FFh が返る。

| 01h | Ch.A トーン分周比 上位 | 分周比 [11:8] |

| 07h | ミキサー / I/O 制御（/ENABLE） | b7: IOB、b6: IOA、b5: NC、b4: NB、b3: NA、b2: TC、b1: TB、b0: TA |

| 0Fh | I/O ポート B | GPIO（4.5 節） |

## 4.4 基本レジスタの機能

基本レジスタの動作は YM2149 と同じである。SSG の基準クロックは MSX 標準の PSG と同じ 1.7897725MHz 相当であり、以下の周波数の計算式もそのまま使える。

### 4.4.1 トーン分周比（00h〜05h）

各チャンネルの矩形波の周波数を 12 ビットの分周比 TP で指定するレジスタで、チャンネルごとに下位（00h／02h／04h）と上位（01h／03h／05h）の 2 本に分かれる。周波数 f は次式で決まる。

- **f = 1789772.5 ／ (16 × TP)**（Hz）

TP が大きいほど音は低くなる。設定値 0 は 1 として扱われ、そのとき周波数は最高の約 111.9kHz になる。逆に TP = 4095 では約 27.3Hz になる。音名との対応の目安を表 4.3 に示す。

### 表 4.3 音名とトーン分周比の目安

| 音名 | 周波数（Hz） | 分周比 TP |
|---|---|---|
| C4 | 261.6 | 427 |
| D4 | 293.7 | 381 |
| E4 | 329.6 | 339 |
| F4 | 349.2 | 320 |
| G4 | 392.0 | 285 |
| A4 | 440.0 | 254 |
| B4 | 493.9 | 227 |
| C5 | 523.3 | 214 |

### 4.4.2 ノイズ分周比（06h）

ノイズジェネレータの周波数を 5 ビットの分周比 NP で指定する。ノイズの基準周波数 f は次式で決まり、NP が大きいほど低い（暗い）ノイズになる。

- **f = 1789772.5 ／ (16 × NP)**（Hz）

ノイズジェネレータは 1 系統だけが内蔵され、3 チャンネルで共用される。どのチャンネルへノイズを出すかはミキサー（07h）で選ぶ。設定値 0 は 1 として扱われる。

### 4.4.3 ミキサー / I/O 制御（07h）

各チャンネルへのトーンとノイズの出力を許可／禁止するレジスタである。ビット配置を図 4.1 に示す。

![07h（ミキサー / I/O 制御）のビット配置](images/bf_ssg_mixer.png)

TA／TB／TC と NA／NB／NC はいずれも **負論理** で、**0 で許可、1 で禁止** である点に注意すること。チャンネルの出力は、許可されたトーンとノイズの論理和になる。トーンとノイズの両方を許可すると、両者が重なって出力される。音を止めるには、音量を 0 にするほか、このレジスタでトーンとノイズの両方を禁止する方法もある。

IOA／IOB は I/O ポート A／B の方向指定で、0 が入力、1 が出力である（4.5 節）。

### 4.4.4 音量（08h〜0Ah）

各チャンネルの音量を 4 ビットで指定する。0 が無音、15 が最大で、音量ステップは対数特性（1 段階で約 3dB の変化）になっているため、小さい値でも急に小さくはならない。

M ビット（b4）が 1 のとき、そのチャンネルの音量は下位 4 ビットではなくエンベロープジェネレータの出力に従う。エンベロープは 3 チャンネルで共用されるため、複数のチャンネルで M を 1 にすると、同じ包絡が各チャンネルにかかる。

### 4.4.5 エンベロープ周期（0Bh、0Ch）

エンベロープ 1 周期の時間を 16 ビットの値 EP で指定する。周期 T は次式で決まる。

- **T = 256 × EP ／ 1789772.5**（秒）

たとえば EP = 6991（1B4Fh）で周期は約 1 秒になる。エンベロープ波形は 1 周期を 32 ステップ（5 ビットの音量段階）で構成する。EP はエンベロープジェネレータ全体で 1 つだけであり、3 チャンネルで共用される。

### 4.4.6 エンベロープ波形（0Dh）

エンベロープの波形を CONT／ATT／ALT／HOLD の 4 ビットで選ぶ。ビット配置を図 4.2 に、各ビットと波形の対応を図 4.3 に示す。

![0Dh（エンベロープ波形）のビット配置](images/bf_ssg_env.png)

![エンベロープ波形（0Dh の CONT／ATT／ALT／HOLD と波形の対応）](images/fig_env_ssg.png)

- **CONT**： 1 では波形を繰り返す。0 では 1 周期だけ波形を出して停止する。
- **ATT**： 1 では上昇型（最小から最大へ）、0 では下降型（最大から最小へ）の波形になる。
- **ALT**： CONT = 1 のとき、周期ごとに波形の極性を反転する。鋸波と組み合わせると三角波になる。
- **HOLD**： 繰り返しが止まった後、その時点のレベルを保持する。ALT と組み合わせると、保持されるレベルが反転側になる。

このレジスタへ書き込むと、エンベロープは波形の先頭から再始動する（リトリガ）。フレーズの頭で発音に合わせて書き直すのが基本的な使い方である。

## 4.5 I/O ポート（GPIO）

各コアのレジスタ 0Eh / 0Fh は汎用 I/O ポート A / B である。カートリッジ上での接続は次のとおりである。

| コア | ポート A（0Eh / 1Eh） | ポート B（0Fh / 1Fh） |
|---|---|---|
| SSG1 | 未接続 | 未接続 |
| SSG2 | 入力： カートリッジの DIP スイッチ（下位 2 ビット、上位ビットは 0） | 未接続（出力は接続されていない） |

SSG2 のポート A を読み出すことで、DIP スイッチの設定状態を知ることができる。07h / 17h の IOA ビットは 0（入力）にしておくこと。

## 4.6 Y8960 拡張レジスタ

### 4.6.1 チャンネル別ゲイン（20h〜26h）

各チャンネルの最終出力レベルを 8 ビットで調整するレジスタである（SSG1： A = 20h、B = 21h、C = 22h。SSG2： A = 24h、B = 25h、C = 26h）。

- 値の範囲は 0〜128 で、**128 が最大**（等倍）、0 で無音になる。
- デフォルトは 128 である。
- このゲインはコアの出力段に作用するため、音量レジスタでエンベロープを選んだチャンネルにも効く。4 ビット音量（＋エンベロープ）で作った音のバランスを、チャンネル単位で微調整する用途に使える。

ミキサー側にも SSG 系統全体のボリューム（MMIO 7FF7h、0 = OFF 〜 128 = MAX）がある。チャンネル別ゲインは各チャンネルの調整、ミキサーボリュームは SSG 系統全体の調整という役割分担である（デジタルミキサーの章を参照）。

### 4.6.2 チャンネル別パン（28h〜2Eh）

各チャンネルのステレオ定位を 8 ビットで指定するレジスタである（SSG1： A = 28h、B = 29h、C = 2Ah。SSG2： A = 2Ch、B = 2Dh、C = 2Eh）。

- **1 で左端、128 で中央、255 で右端**。
- デフォルトは 128（中央）である。
- ノイズとエンベロープはチャンネルの構成要素であり、そのチャンネルに設定したパンとゲインがそのまま適用される。

従来の SSG 音源はモノラルであったため、既存の曲データをそのまま演奏すれば全チャンネル中央定位で再生される。チャンネルごとにパンを振ることで、ステレオ感のある再生が可能になる。

## 4.7 使い方

### 4.7.1 トーンを鳴らす

SSG でトーンを 1 つ鳴らすまでの手順は次のとおりである。

1. I/O イネーブラ（MMIO 7FFFh）の SSG ビットを 1 にして、SSG の I/O ポートを有効化する（第 3 章）。
2. トーン分周比（00h〜05h）に音程に応じた値を書く。
3. ミキサー（07h）で、そのチャンネルのトーンを許可する（対応ビットを 0 にする）。
4. 音量（08h〜0Ah）に 1〜15 を書く。

音を止めるときは、音量を 0 にするか、ミキサーでトーンとノイズの両方を禁止する。サンプル SSG401 は、SSG1 のチャンネル A で A4（440Hz）を鳴らすプログラムである（ファイルはサンプル集に収録）。

```
;-----------------------------------------------------------------------
;	SSG401.asm - SSG のトーンとエンベロープ (Y8960)
;	SSG1 のチャンネル A で A4 (440Hz) を鳴らし、約 1 秒後に
;	エンベロープ (三角波、周期 約 1 秒) へ切り替えるサンプル。
;	4000h 配置の ROM 形式。zma でアセンブルする。
;-----------------------------------------------------------------------
		org		4000h
		db		"AB"
		dw		start

;	SSG1 レジスタ書き込み (A = レジスタ番号, E = データ)
ssg1w:
		out		[0a0h], a
		ld		a, e
		out		[0a1h], a
		ret

start:
		; Enabler2 (MMIO 7FFFh) の SSG ビットを 1 にして SSG を有効化
		ld		a, 02h
		ld		[7fffh], a

		; Ch.A トーン分周比 = 254 (A4 = 約 440Hz)
		ld		a, 00h
		ld		e, 0feh
		call	ssg1w
		ld		a, 01h
		ld		e, 00h
		call	ssg1w

		; ミキサー (07h): トーン A のみ許可 (負論理なので 3Eh)
		ld		a, 07h
		ld		e, 3eh
		call	ssg1w

		; Ch.A 音量 (08h) = 15
		ld		a, 08h
		ld		e, 0fh
		call	ssg1w
		…（約 1 秒待つ）
		…（次項のエンベロープ設定へ続く）
```

### 4.7.2 エンベロープを使う

エンベロープは、音量の時間変化をハードウェアに任せる機能である。手順は、周期（0Bh／0Ch）と波形（0Dh）を設定し、使いたいチャンネルの音量レジスタの M ビットを 1 にすることだけである。SSG401 の後半では、周期約 1 秒の三角波（0Dh = 0Ah）を設定し、チャンネル A の音量が 1 秒周期で上下するようにしている。

```
		; エンベロープ周期 (0Bh/0Ch) = 6991 (周期 約 1 秒)
		ld		a, 0bh
		ld		e, 4fh
		call	ssg1w
		ld		a, 0ch
		ld		e, 1bh
		call	ssg1w

		; エンベロープ波形 (0Dh) = 0Ah (CONT=1, ATT=0, ALT=1, HOLD=0: 三角波)
		; 書き込んだ時点でエンベロープが再始動する
		ld		a, 0dh
		ld		e, 0ah
		call	ssg1w

		; Ch.A 音量 (08h) の M ビットを 1 にしてエンベロープへ切り替え
		ld		a, 08h
		ld		e, 10h
		call	ssg1w
```

エンベロープは 3 チャンネル共用で、周期と波形も 1 系統だけである。チャンネルごとに違う包絡を使いたい場合は、SSG1 と SSG2 に分けるか、音量レジスタをソフトウェアで書き換える方法と使い分けること。

# 第5章 OPLL-EX

## 5.1 概要

OPLL-EX は、YM2413（OPLL）相当の FM 音源である。メロディ 9 チャンネル、または メロディ 6 チャンネル＋リズム 5 音（バスドラム、スネアドラム、タムタム、トップシンバル、ハイハット）の構成を取る。レジスタ構成と基本動作は YM2413 と互換であり、MSX-MUSIC のソフトウェア資産がそのまま利用できる。

Y8960 での拡張は次の 2 点であり、この拡張版を OPLL-EX と呼ぶ。

- **プリセット音色バンクの追加**： YM2413 純正のプリセット音色に加え、OPLL-X（YM2423）、OPLL-P（YMF281）、VRC7 のプリセット音色セットを内蔵し、チャンネルごとに切り替えて使える（5.4 節）。
- **チャンネル別ステレオ定位（パン）**： 9 チャンネルのそれぞれに 8 ビットのパンを指定できる（5.6 節）。YM2413 はモノラル出力であったため、これは Y8960 独自の拡張である。

## 5.2 アクセス方法

### 5.2.1 I/O ポート

| ポート | R/W | 機能 |
|---|---|---|
| 7Ch | W | レジスタアドレスの指定 |
| 7Dh | W | レジスタへの書き込み |

OPLL のレジスタは読み出しできない。書き込みの手順は、7Ch にレジスタアドレスを書き、続いて 7Dh にデータを書く。

電源投入直後は OPLL の I/O ポートは無効化されている。使用するには I/O イネーブラ 1（MMIO 7FF6h の OPLL ビット）を 1 にして有効化する必要がある（第 3 章参照）。

### 5.2.2 メモリマップド I/O（ミラー）

| アドレス | R/W | 機能 |
|---|---|---|
| 7FF4h | W | レジスタアドレスの指定（7Ch と同じ） |
| 7FF5h | W | レジスタへの書き込み（7Dh と同じ） |

ミラーが利用できるメモリ状態の条件については第 3 章を参照すること。

【要確認】 レジスタ書き込み時に必要なウェイト（アドレス書き込み後・データ書き込み後の待ち時間）の規定値。原チップ YM2413 には規定があるが、Y8960 の実装で同じウェイトが必要かは未確認。

## 5.3 レジスタマップ

レジスタはすべて書き込み専用である。00h〜38h が YM2413 互換部、40h〜48h と 50h〜58h が Y8960 の新設レジスタである。

| アドレス | 内容 | 主なビット構成 |
|---|---|---|
| 00h | ユーザー音色： モジュレータ特性 | AM、VIB、EGT、KSR、MULTI [3:0] |
| 01h | ユーザー音色： キャリア特性 | AM、VIB、EGT、KSR、MULTI [3:0] |
| 02h | ユーザー音色： モジュレータ出力レベル | KSL [7:6]、TL [5:0] |
| 03h | ユーザー音色： 変調度・フィードバック | KSL [7:6]、DC、DM、FB [2:0] |
| 04h | ユーザー音色： モジュレータ EG | AR [7:4]、DR [3:0] |
| 05h | ユーザー音色： キャリア EG | AR [7:4]、DR [3:0] |
| 06h | ユーザー音色： モジュレータ EG | SL [7:4]、RR [3:0] |
| 07h | ユーザー音色： キャリア EG | SL [7:4]、RR [3:0] |
| 08h〜0Dh | 未使用 | − |
| 0Eh | リズム制御 | b5: R（リズムモード）、b4: BD、b3: SD、b2: TOM、b1: TC、b0: HH（各リズム音のキーオン） |
| 0Fh | テスト | 常に 0 を書くこと |
| 10h〜18h | Ch.1〜9 F ナンバー下位 | F# [7:0] |
| 19h〜1Fh | 未使用 | − |
| 20h〜28h | Ch.1〜9 制御 | SUS [5]、KEY [4]、BLOCK [3:1]、F# [0]（最上位ビット） |
| 29h〜2Fh | 未使用 | − |
| 30h〜38h | Ch.1〜9 音色・音量 | INST [7:4]（音色番号）、VOL [3:0]（音量） |
| 39h〜3Fh | 未使用 | − |
| **40h〜48h** | **Ch.1〜9 プリセット音色バンク（新設）** | BANK [1:0]（5.4 節） |
| 49h〜4Fh | 未使用 | − |
| **50h〜58h** | **Ch.1〜9 パン（新設）** | PAN [7:0]（5.6 節） |
| 59h〜FFh | 未使用 | − |

### 5.3.1 ユーザー音色レジスタ（00h〜07h）

INST = 0 のときに使われるユーザー音色は、2 つのオペレータ（モジュレータとキャリア）のパラメータで定義する。OPLL の FM は、モジュレータがキャリアの周波数を変調する 2 オペレータ構成であり、モジュレータ側のパラメータが音の「明るさや倍音」を、キャリア側が音量の包絡を主に決める。各レジスタのビット配置は次のとおりである。

![00h／01h（オペレータ特性）のビット配置](images/bf_opll_inst_a.png)

![02h（モジュレータ出力レベル）のビット配置](images/bf_opll_inst_tl.png)

![03h（変調度・フィードバック）のビット配置](images/bf_opll_inst_fb.png)

![04h／05h（AR／DR）のビット配置](images/bf_opll_inst_eg1.png)

![06h／07h（SL／RR）のビット配置](images/bf_opll_inst_eg2.png)

- **MULTI**： オペレータの周波数倍率である。値と倍率の対応は、0 が 1/2 倍、1 が 1 倍、2 が 2 倍、3 が 3 倍、4 が 4 倍、5 が 5 倍、6 が 6 倍、7 が 7 倍、8 が 8 倍、9 が 9 倍、10 と 11 が 10 倍、12 と 13 が 12 倍、14 と 15 が 15 倍である。モジュレータの倍率を変えると倍音の構成が変わる。
- **TL**： モジュレータの出力レベルである。値が小さいほど変調が深くなり、音が明るく（倍音が多く）なる。キャリアの音量は TL ではなくチャンネルごとの VOL（30h〜38h）で決まる。
- **KSL**： 音程が高くなるにつれてオペレータの出力を弱める量である。値が大きいほど、高音域で音が丸く（モジュレータ側では暗く）なる。
- **FB**： モジュレータ自身へのフィードバック量である。値を大きくすると倍音が増えて音が鋭くなる。
- **AM／VIB**： 1 にすると、そのオペレータに内蔵 LFO によるトレモロ（振幅変調）／ビブラート（周波数変調）がかかる。LFO の深さは全オペレータ共通の固定値である。
- **KSR**： 1 にすると、音程が高いほどエンベロープの各レートが速くなる。
- **DC／DM**： オペレータの波形選択である。0 が正弦波、1 が半波波形（正弦波の負側を 0 にした波形）で、半波波形は倍音を多く含む。

エンベロープは AR（アタック）→ DR（ディケイ）→ SL（サステインレベル）→ RR（リリース）の 4 段階で構成される（図 5.1）。EGT が 1（持続型）のオペレータは、キーオン中は SL を保持し続ける。EGT が 0（減衰型）では、SL に到達した後も緩やかに減衰を続け、やがて無音になる。キーオフすると、どちらの型でも RR の速さで減衰する。

![OPLL のエンベロープ（AR／DR／SL／RR と EGT）](images/fig_eg_opll.png)

### 5.3.2 チャンネルレジスタ（10h〜38h）

チャンネルごとの音程は、F ナンバー（9 ビット）と BLOCK（3 ビット）で指定する。発音周波数 f は次式で決まる。

- **f = F# × 2^BLOCK × 3579545 ／ 37748736**（Hz）

BLOCK はオクターブの指定であり、同じ F ナンバーでも BLOCK を 1 上げると音程は 1 オクターブ上がる。BLOCK = 4 のときの音名との対応の目安を表 5.1 に示す。

### 表 5.1 音名と F ナンバーの目安（BLOCK = 4）

| 音名 | 周波数（Hz） | F ナンバー |
|---|---|---|
| C4 | 261.6 | 172 |
| D4 | 293.7 | 194 |
| E4 | 329.6 | 217 |
| F4 | 349.2 | 230 |
| G4 | 392.0 | 258 |
| A4 | 440.0 | 290 |
| B4 | 493.9 | 326 |
| C5 | 523.3 | 345 |

制御レジスタと音色・音量レジスタのビット配置は次のとおりである。

![20h〜28h（チャンネル制御）のビット配置](images/bf_opll_ctrl.png)

![30h〜38h（音色・音量）のビット配置](images/bf_opll_instvol.png)

- **KEY**： 1 でキーオン（発音開始）、0 でキーオフである。キーオンの瞬間にエンベロープが先頭から始まる。
- **SUS**： 1 の間は、KEY を 0 にしてもリリースへ移らず、サステインレベルを保持する（サステインペダル相当）。
- **INST**： 音色番号である。0 がユーザー音色（5.3.1 節）、1〜15 がプリセット音色である。
- **VOL**： チャンネルの音量で、**値が小さいほど音量が大きい**（0 が最大）という逆向きの指定である点に注意すること。

## 5.4 プリセット音色バンク

YM2413 系のプリセット音色は、チップごとに収録内容が異なる。OPLL-EX には次の 4 種類のプリセット音色セット（バンク）が内蔵されている。

| バンク | 内容 |
|---|---|
| OPLL | YM2413 のプリセット音色 |
| OPLL-X | YM2423 のプリセット音色 |
| OPLL-P | YMF281 のプリセット音色 |
| VRC7 | VRC7 のプリセット音色 |

チャンネルごとに、追加レジスタ 40h〜48h（Ch.1 用が 40h、…、Ch.9 用が 48h）の **BANK（下位 2 ビット）** で、そのチャンネルが使うバンクを選択する。30h〜38h の INST（音色番号）は、選択したバンク内のプリセット音色を指す。INST = 0 のユーザー音色（00h〜07h で定義する音色）はバンクによらず共通である。

![40h〜48h（プリセット音色バンク）のビット配置](images/bf_opll_bank.png)

バンクをチャンネルごとに変えられるため、たとえばメロディに VRC7 の音色、伴奏に YM2413 の音色、といった混在使用ができる。

BANK の値とバンクの対応は、BANK = 0 が OPLL（YM2413）、1 が OPLL-X（YM2423）、2 が OPLL-P（YMF281）、3 が VRC7 である。VRC7 バンクも BANK レジスタで選択できる。

## 5.5 リズムモード

レジスタ 0Eh の R ビットを 1 にするとリズムモードになり、メロディ Ch.7〜9 がリズム音（BD / SD / TOM / TC / HH）に置き換わる。0Eh のビット配置は次のとおりである。

![0Eh（リズム制御）のビット配置](images/bf_opll_rhythm.png)

各リズム音と、担当するオペレータ・音量の対応は次のとおりである。音色は担当チャンネルの INST に従う。リズムモードでは 37h／38h の上位 4 ビットは音色番号ではなく、それぞれ HH／TOM の音量として扱われる点に注意すること。

| リズム音 | 内容 | 担当オペレータ | 音量 |
|---|---|---|---|
| BD | バスドラム | Ch.7 のモジュレータとキャリア | 36h の下位 4 ビット |
| HH | ハイハット | Ch.8 のモジュレータ＋ノイズ | 37h の上位 4 ビット |
| SD | スネアドラム | Ch.8 のキャリア＋ノイズ | 37h の下位 4 ビット |
| TOM | タムタム | Ch.9 のモジュレータ | 38h の上位 4 ビット |
| TC | トップシンバル | Ch.9 のキャリア＋ノイズ | 38h の下位 4 ビット |

BD の音程は Ch.7 の F ナンバー、TOM の音程は Ch.9 の F ナンバーで決まる。リズム音を鳴らす手順は、担当チャンネルの INST と音量と（BD / TOM では）F ナンバーを先に設定し、0Eh の該当ビットを 0 → 1 にすることである。ビットを 1 にしたままでは再発音しないため、打つたびにビットを 0 に戻してから 1 にする。リズムモードの間、Ch.7〜9 はメロディとして使えない。

## 5.6 ステレオ定位（パン）

追加レジスタ 50h〜58h（Ch.1 用が 50h、…、Ch.9 用が 58h）で、チャンネルごとにステレオ定位を指定する。

- **1 で左端、128 で中央、255 で右端**。
- デフォルトは 128（中央）である。

ミキサー側にも OPLL 系統全体のボリューム（MMIO 7FF8h、0 = OFF 〜 128 = MAX）がある（デジタルミキサーの章を参照）。

リズムモード時のリズム音 5 音のパンも、担当チャンネルのパン（56h〜58h）に従います。すなわち BD は 56h、HH と SD は 57h、TOM と TC は 58h です。

## 5.7 使い方

### 5.7.1 メロディを鳴らす

OPLL でメロディ音を 1 つ鳴らすまでの手順は次のとおりである。

1. I/O イネーブラ 1（MMIO 7FF6h）の OPLL ビットを 1 にして、OPLL の I/O ポートを有効化する（第 3 章）。
2. チャンネルの音色・音量（30h〜38h）に、INST と VOL を書く。
3. F ナンバー下位（10h〜18h）に、音程の下位 8 ビットを書く。
4. 制御レジスタ（20h〜28h）に、BLOCK と F ナンバーの最上位ビットを書き、最後に KEY を 1 にして発音を開始する。

音を止めるときは KEY を 0 にする。次の音を出すときは、F ナンバーを書き換えてから KEY を 1 にし直す（KEY = 1 のまま F ナンバーだけを変えると、エンベロープは再始動せずに音程だけが変わる。レガート奏法にはこちらを使う）。

サンプル OPLL501 は、Ch.1 でプリセット音色の A4 を鳴らすプログラムである（ファイルはサンプル集に収録）。

```
		; Ch.1 音色・音量 (30h): INST = 1 (バイオリン), VOL = 0 (最大)
		ld		a, 30h
		ld		e, 10h
		call	opllw
		; Ch.1 F ナンバー下位 (10h) = 22h (F# = 290, BLOCK = 4 で A4)
		ld		a, 10h
		ld		e, 22h
		call	opllw
		; Ch.1 制御 (20h): KEY = 1, BLOCK = 4, F# の最上位ビット = 1
		ld		a, 20h
		ld		e, 19h
		call	opllw
		…（約 1 秒待つ）
		; キーオフ (KEY = 0)
		ld		a, 20h
		ld		e, 09h
		call	opllw
```

### 5.7.2 ユーザー音色を作る

プリセット音色の代わりに、00h〜07h へ自作のパラメータを書くとユーザー音色が使えるようになる。ユーザー音色は全チャンネル共通で 1 種類だけであり、INST = 0 を選んだチャンネルがこれを使う。パラメータを書き換えると、発音中のチャンネルの音色もその場で変わる。

作り方の目安は次のとおりである。キャリア側は音の包絡（AR = 15、DR は音の減衰感、SL と RR で余韻）を決め、モジュレータ側は TL で音の明るさを、MULTI と FB で倍音の構成を調整する。OPLL501 の後半では、持続型（EGT = 1）のオルガンに近いパラメータを設定し、同じ A4 をユーザー音色で鳴らし直している。

```
		; ユーザー音色 (00h〜07h) を設定する
		ld		a, 00h			; モジュレータ: EGT=1, MULTI=1
		ld		e, 21h
		call	opllw
		ld		a, 01h			; キャリア: EGT=1, MULTI=1
		ld		e, 21h
		call	opllw
		ld		a, 02h			; モジュレータ TL = 24
		ld		e, 18h
		call	opllw
		ld		a, 03h			; フィードバック = 5
		ld		e, 05h
		call	opllw
		ld		a, 04h			; モジュレータ AR=15, DR=8
		ld		e, 0f8h
		call	opllw
		ld		a, 05h			; キャリア AR=15, DR=6
		ld		e, 0f6h
		call	opllw
		ld		a, 06h			; モジュレータ SL=4, RR=6
		ld		e, 46h
		call	opllw
		ld		a, 07h			; キャリア SL=3, RR=6
		ld		e, 36h
		call	opllw
		; Ch.1 をユーザー音色 (INST = 0), VOL = 2 に切り替えて発音
		ld		a, 30h
		ld		e, 02h
		call	opllw
		ld		a, 20h
		ld		e, 19h
		call	opllw
```

# 第6章 OPL2 ＋ ADPCM

## 6.1 概要

このブロックは、YM3812（OPL2）相当の FM 音源と、ADPCM-B 相当の ADPCM 再生部を 1 つにまとめたものである。レジスタマップは **MSX-AUDIO（Y8950）と互換** に構成されており、MSX-AUDIO 用のソフトウェア資産が利用できる。

- **FM 部**： 2 オペレータ FM、9 チャンネル。リズムモード時はメロディ 6 チャンネル＋リズム 5 音。タイマー 2 本（タイマー 1 / タイマー 2）を内蔵し、割り込みを発生できる。Y8960 の実装はステレオ出力のコアを用いており、チャンネル別パンの拡張が追加されている（6.7 節）。
- **ADPCM 部**： ADPCM-B 方式のサンプル再生。専用の 256KB メモリを持ち、メモリ上の波形データをデルタ変調で再生する。メモリを介さず、CPU がデータレジスタへ直接データを供給する再生（CPU 直接再生、6.6 節）もできる。録音系とメモリ読み書きのためのデータポートも Y8950 と同じ配置にある。

FM 部と ADPCM 部の出力はブロック内で加算・飽和され、ミキサーの「OPL2」入力として 1 系統にまとめられる。したがってミキサー側のボリュームや定位は FM 部と ADPCM 部で共通である（チャンネル別のパンは各部で個別に設定できる）。

Y8950 にあって Y8960 で廃止された機能（キーボード I/O、プリスケーラ、DAC 直接出力など）については 6.5 節に明記する。

## 6.2 アクセス方法

### 6.2.1 I/O ポート

| ポート | R/W | 機能 |
|---|---|---|
| C0h | W | レジスタアドレスの指定 |
| C0h | R | ステータスレジスタの読み出し（6.3 節） |
| C1h | W | レジスタへの書き込み |

書き込みの手順は、C0h にレジスタアドレスを書き、続いて C1h にデータを書く。レジスタ値そのものは読み出せない。

電源投入直後は OPL2 の I/O ポートは無効化されている。使用するには I/O イネーブラ 2（MMIO 7FFFh の OPL2 ビット）を 1 にして有効化する必要がある（第 3 章参照）。

### 6.2.2 メモリマップド I/O（ミラー）

| アドレス | R/W | 機能 |
|---|---|---|
| 7FF2h | W | レジスタアドレスの指定（C0h と同じ） |
| 7FF3h | W | レジスタへの書き込み（C1h と同じ） |

ミラー側は書き込み専用であり、ステータスの読み出しはできない。ミラーが利用できるメモリ状態の条件については第 3 章を参照すること。

【要確認】 レジスタ書き込み時に必要なウェイトの規定値。原チップ YM3812 / Y8950 には規定があるが、Y8960 の実装で同じウェイトが必要かは未確認。

## 6.3 ステータスレジスタ

C0h を読むとステータスレジスタが得られる。割り込み要因の確認に使う。

| ビット | 名称 | 意味 |
|---|---|---|
| b7 | INT | 割り込み発生（いずれかのフラグが立ち、割り込みが許可されている） |
| b6 | T1 | タイマー 1 のフラグ |
| b5 | T2 | タイマー 2 のフラグ |
| b4 | EOS | ADPCM がストップアドレスに到達した |
| b3 | BUF_RDY | バッファレディ（ADPCM データレジスタへのアクセス可） |
| b2〜b1 | − | 1 固定 |
| b0 | PCM_BSY | 再生中（コントロール 1 の START が立っている間）1 |

フラグのマスクとクリアはレジスタ 04h（フラグコントロール）で行う（6.4 節）。割り込み全体の扱いは割り込みの章を参照すること。

ADPCM 関係のフラグの振る舞いは次の通りである。

- リセット直後は EOS / BUF_RDY の各フラグがマスクされており、ステータスの読み値は 06h になる（ADPCM による割り込みも発生しない）。マスクはレジスタ 04h で解除する。
- EOS は、再生がストップアドレスに到達したときに立つ。リピート再生時も、ループの終端ごとに立つ。
- リピートなしの再生が終了すると、コントロール 1 の START などは自動的にクリアされ、PCM_BSY も 0 に戻る。
- BUF_RDY は、待機中とメモリ転送モード中は 1 を保持する。データレジスタ経由の読み書きでは、SRAM への処理が完了するまで 0 になる。CPU 直接再生（6.6 節）では、供給した 1 バイトが消費されると 1 になり、データレジスタへ書き込むと 0 になる。

## 6.4 FM 部レジスタ

レジスタはすべて書き込み専用である。FM 部のアドレス配置と各パラメータの意味は YM3812 と同じであり、本節で説明する。タイマー／フラグ関係は 6.3 節と本節の表に示す。

| アドレス | 内容 | 主なビット構成 |
|---|---|---|
| 01h | テスト／波形選択許可 | b5: WS 許可（1 で E0h〜F5h の波形選択が有効になる）。それ以外のビットはテスト用で、通常は 0 にすること |
| 02h | タイマー 1 | カウンタ値（8 ビット） |
| 03h | タイマー 2 | カウンタ値（8 ビット） |
| 04h | フラグコントロール | b7: IRQRST（フラグリセット）、b6: T1MSK、b5: T2MSK、b4: MSKEDS（EOS マスク）、b3: MSKBR（BUF マスク）、b1: ST2（タイマー 2 始動）、b0: ST1（タイマー 1 始動） |
| 08h | CSM / ノートセレクト | b7: CSM（複合正弦波モード）、b6: NSEL。ADPCM コントロール 2 と共用（6.5 節） |
| 20h〜35h | オペレータ特性 1 | AM、VIB、EGT、KSR、MULTI [3:0] |
| 40h〜55h | オペレータ特性 2 | KSL [7:6]、TL [5:0] |
| 60h〜75h | オペレータ EG 1 | AR [7:4]、DR [3:0] |
| 80h〜95h | オペレータ EG 2 | SL [7:4]、RR [3:0] |
| A0h〜A8h | Ch.1〜9 F ナンバー下位 | F# [7:0] |
| B0h〜B8h | Ch.1〜9 制御 | KON [5]、BLOCK [4:2]、F# [1:0] |
| BDh | リズム / AM・VIB 深さ | AM 深さ [7]、VIB 深さ [6]、R（リズムモード）[5]、BD [4]、SD [3]、TOM [2]、TC [1]、HH [0] |
| C0h〜C8h | Ch.1〜9 接続 | FB [3:1]、C（アルゴリズム）[0] |
| E0h〜F5h | オペレータ波形選択 | WS [1:0]（4 波形から選択） |

### 6.4.1 オペレータレジスタ

各チャンネルは、モジュレータとキャリアの 2 つのオペレータを持つ。オペレータレジスタのアドレスは、レジスタグループのベースアドレスに、チャンネルとオペレータで決まるスロットオフセットを加えたものになる。

| チャンネル | モジュレータ | キャリア |
|---|---|---|
| Ch.1 | 00h | 03h |
| Ch.2 | 01h | 04h |
| Ch.3 | 02h | 05h |
| Ch.4 | 08h | 0Bh |
| Ch.5 | 09h | 0Ch |
| Ch.6 | 0Ah | 0Dh |
| Ch.7 | 10h | 13h |
| Ch.8 | 11h | 14h |
| Ch.9 | 12h | 15h |

たとえば Ch.5 キャリアの AR／DR を設定するには、60h + 0Ch = 6Ch へ書く。各レジスタのビット配置は次のとおりである。

![40h〜55h（オペレータ特性 2）のビット配置](images/bf_opl2_op_tl.png)

![60h〜75h（オペレータ EG 1）のビット配置](images/bf_opl2_op_eg1.png)

![80h〜95h（オペレータ EG 2）のビット配置](images/bf_opl2_op_eg2.png)

![E0h〜F5h（オペレータ波形選択）のビット配置](images/bf_opl2_op_ws.png)

パラメータの意味は OPLL（5.3.1 節）と同じものが多い。OPL2 固有の点は次のとおりである。

- **TL**： 1 段階は約 0.75dB で、OPLL より細かく調整できる。FM 接続では、キャリアの TL がそのままチャンネルの音量になる。
- **WS（波形選択）**： オペレータの波形を、正弦波／半波／全波整流／パルス波の 4 種から選べる。全波整流やパルス波は倍音を多く含み、変調側に使うと明るい音になる。**レジスタ 01h の b5 を 1 にしておかないと、WS は無効で全オペレータが正弦波になる**点に注意すること。
- **EG**： エンベロープの形は図 6.1 のとおりで、EGT ビットで持続型／減衰型を選ぶ点も OPLL と同じである。AR = 0 のオペレータは発音しない（アタックが始まらない）。

BLOCK = 4 のときの音名との対応の目安を表 6.1 に示す。

- **CON**： 2 つのオペレータの接続方式である。0（FM 接続）ではモジュレータがキャリアを変調し、出力はキャリアだけから取り出される。1（加算接続）では両オペレータの出力が加算され、モジュレータはフィードバック付きの独立した発音体として働く。
- **FB**： FM 接続・加算接続のどちらでも、モジュレータへのフィードバック量を指定する。

### 6.4.3 リズムモード

BDh の R ビットを 1 にするとリズムモードになり、メロディ Ch.7〜9 がリズム音（BD／SD／TOM／TC／HH）に置き換わる。BDh はリズム制御と、全オペレータ共通の AM／VIB 深さを兼ねる。

![BDh（リズム / AM・VIB 深さ）のビット配置](images/bf_opl2_rhythm.png)

リズム音とチャンネルの対応、および鳴らし方は OPLL のリズムモード（5.5 節）と同じである。対応チャンネル（Ch.7〜9）の音色パラメータと VOL に相当するキャリア TL、BD／TOM では F ナンバーを先に設定し、BDh の該当ビットを 0 → 1 にして発音する。

### 廃止されたレジスタ

次の Y8950 の機能は Y8960 には存在しない。書き込んでも動作しない。

| アドレス | Y8950 での機能 | 備考 |
|---|---|---|
| 05h / 06h | キーボード入出力 | 廃止 |
| 0Dh / 0Eh | プリスケーラ | 廃止（再生レートは DELTA-N で直接設定する） |
| 15h / 16h | DAC データ | 廃止 |
| 17h | シフトレジスタ | 廃止 |
| 18h / 19h / 1Ah | I/O コントロール、I/O データ、PCM データ | 廃止 |

レジスタ 08h のメモリ種別指定は、Y8960 でも有効である。**64K** を立てると、メモリアクセスのアドレスは下位 16 ビットにマスクされ、64KB の範囲内で折り返す。**ROM** を立てると、メモリ読み出しは 0 を返し、書き込みは無視される（ROM バンクを模した動作）。SMPL / DA/AD のビットは無効である。データレジスタから直接サンプルを供給する再生（CPU 直接再生）には対応しており、コントロール 1 の MEMD を 0 にして開始する（6.6 節）。

**録音（REC）は未対応**である。START と REC を立てても録音は行われず、アナログ入力の経路もない。REC ビットは、メモリ書き込みモードの選択（6.6 節）にのみ使われる。

## 6.6 ADPCM メモリ

ADPCM 部は、SerialSRAM の中に **専用の 256KB メモリ**を持つ。この領域は CPU バンク領域（BANK#0〜31）とは別の領域であり、容量や構成の切り替えはない（固定）。

- **アドレス指定**： スタートアドレス（09h / 0Ah）とストップアドレス（0Bh / 0Ch）は **4 バイト単位** で指定する。レジスタに書いた 16 ビットの値 × 4 がバイトアドレスとなり、256KB の全域を指せる。再生・転送の範囲はスタートアドレス × 4 からストップアドレス × 4 ＋ 3 までで、ストップ側は末尾の 4 バイトを含む。
- **再生**： START を立てると（MEMD = 1、REC = 0）、スタートアドレスからストップアドレスまでのデータを順に読み出して再生する。REPT を立てるとストップアドレス到達後にスタートアドレスへ戻って繰り返す。到達時はステータスの EOS フラグが立つ。
- **CPU 直接再生**： コントロール 1 を START = 1、REC = 0、MEMD = 0（07h へ 80h）にすると、メモリではなくデータレジスタ（0Fh）へ書いた値が ADPCM データとしてデコードされる。1 バイトが 2 サンプル（上位ニブルが先）で、バイトは上位ニブルがデコードされた時点で消費され、その時点で BUF_RDY が 1 になる。データレジスタへ書き込むと BUF_RDY は 0 になるので、CPU は BUF_RDY を見て次のバイトを書く。開始直後は BUF_RDY が 1 のままであるため、まず 1 バイト目を書いてから BUF_RDY 待ちに入ること。供給が間に合わない場合は、最後に書いたバイトが繰り返し使われる。スタート／ストップアドレスによる終了判定はなく、EOS は立たない。コントロール 1 を書き換えるまで再生が続き、PCM_BSY はその間 1 のままである。SRAM へのアクセスは発生しない。DELTA-N、EG コントロール（12h）、SPOFF、パン（FFh）はメモリ再生と同じに効く。
- **CPU からの読み書き**： レジスタ 0Fh（ADPCM データ）を通じて行う。書き込みモード（START = 0、REC = 1、MEMD = 1）では、0Fh への書き込みのたびに内部アドレスが自動で進み、ストップアドレスの末尾に達すると EOS フラグが立ってポインタはスタートアドレスに戻る（末尾を書いた後も書き込みを続けると、先頭から上書きされていく。ポインタがストップアドレスを超えた位置にあるときの書き込みは無視される）。読み出しモード（START = 0、REC = 0、MEMD = 1）では、コントロール 1 を設定した直後の 2 回の読み出しがダミーとなり、3 回目からプリフェッチされたデータが返る。ストップアドレスを超えて読むと 0 が返り、EOS フラグが立つ。読み書きの開始前に、スタート／ストップアドレスとコントロール 1 の MEMD 等を設定しておくこと。ステータスの BUF_RDY フラグがデータ転送の可否を示す。
- **再生レート**： DELTA-N（10h / 11h、16 ビット）で設定する。値が大きいほど再生が速く（サンプリングレートが高く）なる。
- 再生中でも CPU からのメモリアクセスは可能であり、SRAM へのアクセスは内部で調停される。

## 6.7 パンとボリューム

### 6.7.1 チャンネル別パン（新設）

Y8960 で新設されたレジスタで、チャンネルごとにステレオ定位を指定する。

| アドレス | 内容 |
|---|---|
| F6h〜FEh | FM Ch.1〜9 のパン |
| FFh | ADPCM のパン |

- **1 で左端、128 で中央、255 で右端**。
- デフォルトは 128（中央）である。

### 6.7.2 系統ボリューム

ミキサー側に OPL2 系統（FM 部＋ADPCM 部の合算）のボリューム（MMIO 7FF9h、0 = OFF 〜 128 = MAX）がある（デジタルミキサーの章を参照）。チャンネル別の音量は FM 部の TL や ADPCM の EG コントロールで調整し、系統全体の音量はミキサーボリュームで調整する、という役割分担である。

## 6.8 割り込み

このブロックは割り込み要因として、タイマー 1 / タイマー 2 のタイムアウト、ADPCM の EOS、BUF を持つ。各フラグはレジスタ 04h でマスクでき、フラグが立ってマスクされていない要因があると割り込み信号がアサートされる。詳細は割り込みの章を参照すること。

## 6.9 使い方

### 6.9.1 FM 音を鳴らす

OPL2 で FM 音を 1 つ鳴らすまでの手順は次のとおりである。

1. I/O イネーブラ（MMIO 7FFFh）の OPL2 ビットを 1 にして、OPL2 の I/O ポートを有効化する（第 3 章）。
2. 波形選択を使う場合は、レジスタ 01h の b5 を 1 にする。
3. チャンネルの両オペレータのパラメータ（20h〜F5h の各グループ）を設定する。
4. 接続レジスタ（C0h〜C8h）に FB と CON を設定する。
5. F ナンバー下位（A0h〜A8h）を書き、制御レジスタ（B0h〜B8h）に BLOCK と F ナンバー上位を書いて、最後に KON を 1 にする。

音を止めるときは KON を 0 にする。サンプル OPL601 は、Ch.1 に簡単な FM 音色を設定して A4 を鳴らすプログラムである（ファイルはサンプル集に収録）。

```
		;--- Ch.1 モジュレータ (スロット 00h) ---
		ld		a, 20h			; MULTI = 1
		ld		e, 01h
		call	opl2w
		ld		a, 40h			; TL = 24
		ld		e, 18h
		call	opl2w
		ld		a, 60h			; AR = 15, DR = 6
		ld		e, 0f6h
		call	opl2w
		ld		a, 80h			; SL = 6, RR = 6
		ld		e, 66h
		call	opl2w

		;--- Ch.1 キャリア (スロット 03h) ---
		ld		a, 23h			; MULTI = 1
		ld		e, 01h
		call	opl2w
		ld		a, 43h			; TL = 0 (最大)
		ld		e, 00h
		call	opl2w
		ld		a, 63h			; AR = 15, DR = 4
		ld		e, 0f4h
		call	opl2w
		ld		a, 83h			; SL = 4, RR = 6
		ld		e, 46h
		call	opl2w

		; Ch.1 接続 (C0h): FB = 4, CON = 0 (FM 接続)
		ld		a, 0c0h
		ld		e, 08h
		call	opl2w

		; Ch.1 F ナンバー (A0h/B0h): F# = 580, BLOCK = 4 → A4
		ld		a, 0a0h
		ld		e, 44h			; F# 下位 (580 = 244h)
		call	opl2w
		ld		a, 0b0h
		ld		e, 32h			; KON = 1, BLOCK = 4, F# 上位 = 2
		call	opl2w
```

### 6.9.2 ADPCM を再生する

ADPCM の再生は、データを先にメモリへ書き込んでから行う。おおまかな手順は次のとおりである（レジスタの詳細は 6.5 節と 6.6 節）。

1. スタート／ストップアドレス（09h〜0Ch）を 4 バイト単位で設定する。
2. コントロール 1（07h）に書き込みモード（START = 0、REC = 1、MEMD = 1）を設定し、データレジスタ（0Fh）へ ADPCM データを順に書く。アドレスは自動で進む。
3. DELTA-N（10h／11h）に再生レートを設定する。
4. コントロール 1 に再生モード（START = 1、REC = 0、MEMD = 1）を設定すると再生が始まる。繰り返す場合は REPT も立てる。
5. 再生の終了は、ステータスの EOS フラグ（6.3 節）で知ることができる。

再生レートと音程の関係は、DELTA-N = 8000h のとき約 24.9kHz サンプリングになる。元のサンプルを等速で再生するには、エンコード時のサンプリングレートに対応する DELTA-N を選ぶこと。

### 6.9.3 ADPCM を CPU から直接供給して再生する

メモリへ転送せず、CPU がデータを供給し続けて再生することもできる（CPU 直接再生、6.6 節）。手順は次のとおりである。

1. DELTA-N（10h／11h）に再生レートを設定する。
2. コントロール 1（07h）に CPU 直接再生（START = 1、REC = 0、MEMD = 0）を設定すると再生が始まる。
3. 直ちに最初の 1 バイトをデータレジスタ（0Fh）へ書く。開始直後は BUF_RDY が 1 のままなので、待たずに書くこと。
4. 以後はステータスの BUF_RDY が 1 になるたびに、次の 1 バイトをデータレジスタへ書く。
5. 止めるときはコントロール 1 を書き換える（START = 0 にする、または RST ビットを立てる）。

この方式では EOS による終了検出はできない。サンプル ADCPU は、ファイルの内容をこの方式で再生するプログラムで、Y8960_Cartridge リポジトリの y8960_adpcm_test に収録されている。

# 第7章 SCC

本章では、Y8960 に搭載された SCC（波形メモリ音源）と、そのレジスタについて説明します。SCC はメモリーマップド I/O 専用のブロックであり、メガROM のバンク制御も兼ねています。バンク制御の仕組みそのものは第3章「3.5 メモリーマップとバンク制御」で説明しました。本章では主に音源としてのレジスタを扱い、バンク制御については音源と関係する範囲で触れます。

## 7.1 概要

Y8960 の SCC は、IKASCC（コナミ SCC の再現コア）をベースにしています。主な仕様は次のとおりです。

- 波形メモリ音源 5 チャンネル（Ch.A～Ch.E）
- 各チャンネルは 32 バイトの波形メモリを持ち、その内容を繰り返し読み出して発音します。ただし Ch.D と Ch.E は 1 つの波形メモリを共有します（原 SCC と同じ構成です）
- チャンネルごとに周波数（12 ビット周期値）と音量（4 ビット）を設定できます
- Y8960 独自の拡張として、チャンネルごとにステレオ定位（パン）を指定できます（7.7 節）
- メガROM バンク制御（SCC バンク）を兼ねており、カートリッジの SerialSRAM を MSX のメモリー空間に出現させる役割を持ちます

SCC には I/O ポートは割り当てられていません。すべてのレジスタは、SCC レジスタバンクをメモリー空間に出現させてアクセスします。

## 7.2 SCC レジスタバンクの出現方法

SCC のレジスタは、BANK#63 を出現させたバンク内に現れます（第3章 3.5.3 参照）。

| 条件 | 出現場所 | レジスタのベースアドレス |
|---|---|---|
| BANK2 に BANK#63 を出現（RAM モードによらない） | 8000h～9FFFh | 9800h～9FFFh |
| RAM モード = 1 で BANK1 に BANK#63 を出現 | 6000h～7FFFh | 7800h～7FFFh |

以降の説明では BANK2 に出現させた場合のアドレス（98xxh）を主に記し、BANK1 の場合は 78xxh と読み替えてください。

## 7.3 レジスタマップ

## 7.4 波形メモリ

各チャンネルの波形メモリは 32 バイトで、1 サンプル 8 ビットの符号付き波形データを格納します。発音中、チャンネルは波形メモリを先頭から繰り返し読み出し、1 周期 32 サンプルの波形として出力します。サンプル値 0 が波形の中心（無音時のレベル）であり、正の値と負の値で上下に振れるデータを書きます。基本的な波形の例を図 7.1 に示します。

![波形メモリに書く基本波形の例（32 サンプル）](images/fig_scc_wave.png)

- 波形メモリは読み書き可能です。発音中に書き換えると、その時点から波形が変化します
- Ch.D と Ch.E は波形メモリを共有します。9860h～987Fh への書き込みは両チャンネルの音色を同時に変えます。独立した波形を持たせたい場合は、どちらか一方のチャンネルだけを使うなどの工夫が必要です

波形の作り方が音色を決めます。サイン波は倍音を含まない柔らかい音、矩形波やノコギリ波は倍音の多い明るい音になります。任意の波形を書けるため、楽器音の 1 周期を切り出して書き込むといった使い方もできます。サイン波のデータは 7.10 節のサンプル（SCC701）に収録しています。

## 7.5 周波数レジスタと音量

周波数レジスタは各チャンネル 2 バイトで、下位アドレスに周期値の下位 8 ビット、上位アドレスに上位 4 ビットを書き込みます（12 ビット値）。

発音周波数は原 SCC と同様に次の式で決まります。

> 発音周波数 ＝ 3.579545 MHz ÷ （32 × （周期値 ＋ 1））

周期値が大きいほど低い音になります。音名との対応の目安を表 7.1 に示します。

### 表 7.1 音名と周期値の目安

| 音名 | 周波数（Hz） | 周期値 |
|---|---|---|
| C4 | 261.6 | 426 |
| D4 | 293.7 | 380 |
| E4 | 329.6 | 338 |
| F4 | 349.2 | 319 |
| G4 | 392.0 | 284 |
| A4 | 440.0 | 253 |
| B4 | 493.9 | 225 |
| C5 | 523.3 | 213 |

音量レジスタは各チャンネル 1 バイトで、下位 4 ビットが有効です（0＝無音、15＝最大）。

## 7.6 出力スイッチ

988Fh の出力スイッチは、チャンネルごとの出力オン／オフを制御します。

| ビット | 対象 | 意味 |
|---|---|---|
| bit0 | Ch.A | 1 ＝ 出力オン、0 ＝ 出力オフ |
| bit1 | Ch.B | 同上 |
| bit2 | Ch.C | 同上 |
| bit3 | Ch.D | 同上 |
| bit4 | Ch.E | 同上 |
| bit7～5 | － | 使用しません |

![988Fh（出力スイッチ）のビット配置](images/bf_scc_outsw.png)

リセット時の値は全ビット 0 で、全チャンネルが出力オフです。周波数と音量を設定しただけでは音は出ません。発音したいチャンネルのビットを 1 にしてください。

## 7.7 ステレオ定位（パン）

9900h～9904h は、Y8960 で追加されたチャンネルごとのステレオ定位レジスタです。各チャンネルに 8 ビットで定位を指定します。

- 1 ＝ 左端
- 128 ＝ 中央（リセット時の初期値）
- 255 ＝ 右端

書き込み専用です（読み出し結果は未定義）。リセット時は全チャンネル 128（中央）に戻ります。

## 7.8 モードレジスタ

98E0h～98FFh はモードレジスタです。領域全体で実体は 1 バイトであり、範囲内のどのアドレスに書き込んでも同じレジスタが更新されます。これは原 SCC のテスト系レジスタに相当するもので、通常の演奏プログラムでは書き換える必要はありません（リセット時の値 00h のまま使用してください）。

- 【要確認】モードレジスタの各ビットの機能定義は、現行の仕様資料に記載がありません。詳細が判明し次第、本節に追記します。

## 7.9 バンク制御との関係

SCC コアは音源であると同時に、カートリッジ全体のメモリーバンク制御を担っています。プログラミング上の要点だけを挙げます。詳細は第3章 3.5 を参照してください。

- バンクは 4000h～5FFFh（BANK0）、6000h～7FFFh（BANK1）、8000h～9FFFh（BANK2）、A000h～BFFFh（BANK3）の 4 つで、各 8KB です
- バンクレジスタの配置は RAM モードで変わります。RAM モード = 0 では各バンク内のアドレス（5000h～57FFh、7000h～77FFh、9000h～97FFh、B000h～B7FFh）への書き込み、RAM モード = 1 では 4XFCh～4XFFh への書き込みです。モードレジスタ（RAM モード指定）は 4XFBh で、常に出現しています
- BANK#0～#15 は ROM 扱い、BANK#16～#31 は RAM 扱いのバンクです。RAM バンクへの書き込みは RAM モード = 1 のときだけ有効です
- BANK#63 は SCC レジスタバンク専用です（7.2 節）。それ以外のバンクに出現させてもレジスタとしては機能しません
- リセット時は BANK0～BANK3 に BANK#0～#3 が順に出現し、RAM モード = 0 になっています

## 7.10 発音までの手順

1. BANK#63 を BANK2（または RAM モード = 1 で BANK1）に出現させる
2. 波形メモリに波形データを書き込む
3. 周波数レジスタと音量を設定する
4. 必要に応じてステレオ定位（9900h～9904h）を設定する
5. 出力スイッチ（988Fh）で発音するチャンネルのビットを 1 にする

サンプル SCC701 は、Ch.A にサイン波を書き込んで A4 を鳴らすプログラムです（ファイルはサンプル集に収録）。波形データの並びがそのまま音色になることが分かります。

```
		; BANK2 (8000h〜9FFFh) に BANK#63 (SCC レジスタバンク) を出現させる
		; RAM モード = 0 では 9000h への書き込みが BANK2 のバンク切替になる
		ld		a, 3fh
		ld		[9000h], a

		; Ch.A 波形メモリ (9800h〜981Fh) にサイン波を書き込む
		ld		hl, sine_wave
		ld		de, 9800h
		ld		bc, 32
		ldir

		; Ch.A 周波数 (9880h/9881h): 周期値 = 253 → A4 (約 440Hz)
		ld		a, 0fdh
		ld		[9880h], a
		ld		a, 00h
		ld		[9881h], a

		; Ch.A 音量 (988Ah) = 15
		ld		a, 0fh
		ld		[988ah], a

		; 出力スイッチ (988Fh): Ch.A をオン
		ld		a, 01h
		ld		[988fh], a
```

# 第8章 OPM

本章では、Y8960 に搭載された OPM（YM2151 相当）の FM 音源について説明します。OPM は Y8960 の音源ブロックの中でも後から追加されたもので、旧来の書きかけ資料には記載がありませんでした。本章が本書での正式な解説となります。

## 8.1 概要

Y8960 の OPM は、IKAOPM（YM2151 の再現コア）をベースにしています。主な仕様は次のとおりです。

- 4 オペレーター FM 音源、8 チャンネル
- チャンネルごとにアルゴリズム（接続形態）とフィードバックを設定可能
- ステレオ出力。チャンネルごとに左右への出力可否（RL ビット）を指定できます
- LFO（ビブラート／トレモロ用）とノイズジェネレーターを搭載
- タイマー A／タイマー B を内蔵し、割り込みを発生できます

レジスタ構成は YM2151 と互換です。本章ではアクセス方法と Y8960 固有の実装（書き込みキューなど）に加えて、全レジスタの意味を説明します。

## 8.2 アクセス方法

OPM には I/O ポートとメモリーマップド I/O の 2 系統のアクセス方法があります。

| アクセス先 | アドレスレジスタ | データレジスタ | 備考 |
|---|---|---|---|
| I/O ポート | 7Eh | 7Fh | データ側の読み出しでステータスを取得可能 |
| メモリーマップド I/O | 7FFBh | 7FFCh | 書き込み専用 |

レジスタへの書き込み手順は次のとおりです。

1. アドレスレジスタに、書きたい OPM レジスタの番号を書く
2. データレジスタに、値を書く

I/O ポート（7Eh／7Fh）を使う場合は、あらかじめ I/O ポートを有効化しておく必要があります（I/O Enabler2 の OPM ビット。第3章 3.3 参照）。電源投入直後は無効です。メモリーマップド I/O は、第3章 3.4 のウィンドウが開いているときに使えます。

## 8.3 書き込みキューと /WAIT

YM2151 には「前の書き込みの処理が終わる前に次の書き込みが来ると、その書き込みが取りこぼされる」という性質があり、実チップではステータスの BUSY を見ながら書き込む必要がありました。

Y8960 の OPM では、この制約をハードウェア側で吸収しています。

- CPU からの書き込みは、内部のキュー（16 件分）に順に蓄えられます
- キューからは YM2151 の処理タイミングに合わせて 1 件ずつ取り出され、コアへ書き込まれます（アドレス書き込み・データ書き込みそれぞれに必要な保持時間が確保されます）
- キューが満杯になると、スロットの /WAIT 信号で CPU を待たせます。書き込みが取りこぼされることはありません

したがって、プログラムは BUSY を厳密に監視しなくても、通常の OUT 命令のペースで続けて書き込めます。ただし、キューの深さには限りがあるため、短時間に大量のレジスタ書き換えを行うと /WAIT による待ちが発生し、CPU の処理時間が延びる点に留意してください。

ステータスレジスタの BUSY ビット（8.4 節）は、キューに未処理の書き込みが残っている間、またはコアが処理中の間 1 になります。「すべての書き込みがコアへ反映されたこと」を確認したい場合は、BUSY が 0 になるのを待ってください。

## 8.4 ステータスレジスタ

I/O ポート 7Fh を読み出すと、ステータスレジスタが得られます（メモリーマップド I/O 側からは読み出せません）。

| ビット | 名称 | 意味 |
|---|---|---|
| bit7 | BUSY | 1 ＝ 書き込み処理中（キュー残量あり、またはコア処理中） |
| bit1 | FBT | タイマー B のオーバーフローフラグ |
| bit0 | FTA | タイマー A のオーバーフローフラグ |
| その他 | － | 0 |

タイマーフラグのクリア方法は 8.7 節を参照してください。

## 8.5 レジスタマップ

OPM のレジスタは YM2151 と同じ配置です。各レジスタの詳細は 8.5.1 項以降で説明します。

| レジスタ | 内容 |
|---|---|
| 01h | テストレジスタ（通常は 00h のまま） |
| 08h | キーオン／キーオフ（チャンネルとオペレーターを指定） |
| 0Fh | ノイズ制御（NE：ノイズ有効、NFRQ：ノイズ周波数） |
| 10h | タイマー A カウンタ（上位 8 ビット） |
| 11h | タイマー A カウンタ（下位 2 ビット） |
| 12h | タイマー B カウンタ |
| 14h | タイマー制御（CSM、フラグリセット、割り込み許可、ロード） |
| 18h | LFO 周波数 |
| 19h | LFO 振幅変調深度（AMD）／位相変調深度（PMD）。bit7 で対象を選択して 2 回に分けて書く |
| 1Bh | LFO 波形選択 |
| 20h～27h | チャンネル制御（RL：左右出力、FB：フィードバック量、CON：アルゴリズム） |
| 28h～2Fh | チャンネルごとのキーコード（KC） |
| 30h～37h | チャンネルごとのキー・フラクション（KF） |
| 38h～3Fh | チャンネルごとの PMS（位相変調感度）／AMS（振幅変調感度） |
| 40h～5Fh | オペレーターの DT1（デチューン 1）／MUL（周波数倍率） |
| 60h～7Fh | オペレーターの TL（トータルレベル） |
| 80h～9Fh | オペレーターの KS（キースケーリング）／AR（アタックレート） |
| A0h～BFh | オペレーターの AME（AM 有効）／D1R（第 1 ディケイレート） |
| C0h～DFh | オペレーターの DT2（デチューン 2）／D2R（第 2 ディケイレート） |
| E0h～FFh | オペレーターの D1L（第 1 ディケイレベル）／RR（リリースレート） |

チャンネル別レジスタ（20h～3Fh）はアドレスの下位 3 ビットでチャンネルを、オペレーター別レジスタ（40h～FFh）はアドレスの下位 5 ビットでチャンネルとオペレーターを選択します（YM2151 と同じ規則です）。

### 8.5.1 グローバルレジスタ

**キーオン／キーオフ（08h）**

発音の開始と停止は、音色パラメータとは独立したこのレジスタで行います。オペレータ単位で指定できるため、アルゴリズムの出力側（キャリア側）のオペレータだけをキーオフして余韻を変える、といった使い方もできます。

![08h（キーオン／キーオフ）のビット配置](images/bf_opm_kon.png)

**ノイズ制御（0Fh）**

![0Fh（ノイズ制御）のビット配置](images/bf_opm_noise.png)

NE を 1 にすると、Ch.8 の C2 の出力がノイズに置き換わります。ノイズの音量や包絡は、Ch.8 の C2 のパラメータ（TL や EG）で制御します。

**タイマー制御（14h）とカウンタ（10h～12h）**

![14h（タイマー制御）のビット配置](images/bf_opm_timer_ctrl.png)

タイマー A のカウンタ値は 10 ビットで、10h に上位 8 ビット、11h の下位 2 ビットに下位を書きます。タイマー B は 12h の 8 ビットです。周期の目安は、タイマー A が (1024 − 設定値) × 約 17.9µs、タイマー B が (256 − 設定値) × 約 286µs です。使い方は 8.7 節を参照してください。

**LFO（18h、19h、1Bh）**

LFO は全チャンネル共通の低周波発振器で、ビブラート（位相変調）とトレモロ（振幅変調）に使います。18h が周波数（値が大きいほど速く、約 0.008Hz～36Hz の範囲）、1Bh が波形です。変調の深さは 19h で、bit7 で AMD（振幅変調深度）か PMD（位相変調深度）かを選んで別々に書きます。実際に各チャンネルへどう効くかは、チャンネルごとの PMS／AMS（8.5.2 項）と、オペレータごとの AME（8.5.3 項）で決まります。

![19h（LFO 変調深度）のビット配置](images/bf_opm_amd_pmd.png)

![1Bh（LFO 波形選択）のビット配置](images/bf_opm_lfo_wf.png)

**テストレジスタ（01h）** は通常 00h のままにしてください。

### 8.5.2 チャンネルレジスタ

![20h〜27h（チャンネル制御）のビット配置](images/bf_opm_ch.png)

CON（アルゴリズム）は、4 つのオペレータの接続形態を 8 種類から選びます。接続と、どのオペレータが出力になるかを図 8.1 に示します。M1 には全アルゴリズム共通で、FB の量だけ自己フィードバックがかかります。直列の段数が多いアルゴリズムほど倍音の多い複雑な音になり、並列の多いアルゴリズムは複数の音を重ねる用途に向きます。

![アルゴリズム（CON 0〜7 のオペレータ接続。▼が出力になるオペレータ）](images/fig_opm_alg.png)

音程は KC と KF で指定します。KC の NOTE コードは、オクターブ内で表 8.1 の値を取ります。C だけはコード 14 を下のオクターブ側で使う（たとえば C4 は OCT = 3、NOTE = 14 で KC = 3Eh）点に注意してください。

![28h〜2Fh（キーコード）のビット配置](images/bf_opm_kc.png)

### 表 8.1 NOTE コードと KC の例

| 音名 | NOTE コード | KC（例） |
|---|---|---|
| C | 14 | 3Eh（C4） |
| C# | 0 | 40h（C#4） |
| D | 1 | 41h |
| D# | 2 | 42h |
| E | 4 | 44h |
| F | 5 | 45h |
| F# | 6 | 46h |
| G | 8 | 48h |
| G# | 9 | 49h |
| A | 10 | 4Ah（A4 = 440Hz） |
| A# | 12 | 4Ch |
| B | 13 | 4Dh |

![30h〜37h（キー・フラクション）のビット配置](images/bf_opm_kf.png)

![38h〜3Fh（PMS／AMS）のビット配置](images/bf_opm_pmsams.png)

PMS／AMS は、そのチャンネルが LFO の変調をどれだけ受けるかの感度です。PMS = 0 または AMS = 0 のチャンネルには、LFO の深さ（19h）を設定しても変調がかかりません。

### 8.5.3 オペレータレジスタ

オペレータレジスタ（40h〜FFh）のアドレスは、グループのベースアドレスに「オペレータオフセット＋チャンネル番号」を加えたものです。

| オペレータ | オフセット |
|---|---|
| M1 | 00h |
| M2 | 08h |
| C1 | 10h |
| C2 | 18h |

たとえば Ch.3（チャンネル番号 2）の C1 の TL は、60h + 10h + 2 = 72h です。各レジスタのビット配置は次のとおりです。

![40h〜5Fh（DT1／MUL）のビット配置](images/bf_opm_dt1mul.png)

![60h〜7Fh（TL）のビット配置](images/bf_opm_tl.png)

![80h〜9Fh（KS／AR）のビット配置](images/bf_opm_ksar.png)

![A0h〜BFh（AME／D1R）のビット配置](images/bf_opm_amed1r.png)

![C0h〜DFh（DT2／D2R）のビット配置](images/bf_opm_dt2d2r.png)

![E0h〜FFh（D1L／RR）のビット配置](images/bf_opm_d1lrr.png)

- **MUL／DT1／DT2**： オペレータの周波数は、チャンネルの基本周波数 × MUL が基本になり、DT1 と DT2 でずれを加えます。DT1 は微調整用で、0 と 4 がずれなし、1〜3 が + 方向、5〜7 が − 方向への 3 段階のずれです。DT2 は粗いずれで、音程のずれは 0 = なし、1 = 約 +600 セント、2 = 約 +781 セント、3 = 約 +950 セントになります。モジュレータ側の周波数比を変えると倍音の構成が変わります。
- **TL**： 出力側（キャリア側）のオペレータでは音量そのもので、変調側のオペレータでは変調の深さ（音の明るさ）を決めます。
- **エンベロープ**： AR → D1R → D1L → D2R の順に進む 4 段階構成です（図 8.2）。キーオン中は、D1L に到達した後も D2R の速さで減衰し続けます（D2R = 0 なら D1L を保持します）。キーオフすると RR の速さで減衰します。AR = 0 のオペレータは発音しません。

![OPM のエンベロープ（AR／D1R／D1L／D2R／RR）](images/fig_opm_eg.png)

## 8.6 ステレオ出力（RL ビット）

レジスタ 20h～27h の RL ビットで、チャンネルごとに左右どちらの出力へ送るかを指定します。

| bit7（R） | bit6（L） | 出力 |
|---|---|---|
| 0 | 0 | 左右とも出力しない |
| 0 | 1 | 左のみ |
| 1 | 0 | 右のみ |
| 1 | 1 | 左右（中央） |

OPM のステレオ定位はこの RL ビットによるものがすべてで、ミキサー側にチャンネル単位の細かいパン設定はありません（ミキサーについては第9章）。きめ細かい定位が必要な場合は、同じ音色を 2 チャンネルに割り当て、左右の TL を変えて再現するなどの方法が考えられます。

## 8.7 タイマーと割り込み

OPM はタイマー A とタイマー B を内蔵しています。

- タイマー A は 10 ビット、タイマー B は 8 ビットのカウンタ値を持ち、レジスタ 10h～12h で設定します
- レジスタ 14h で各タイマーのロード（カウント開始）と割り込み許可、フラグのリセットを制御します
- カウンタがオーバーフローすると、ステータスレジスタ（8.4 節）の対応するフラグ（FTA／FBT）が立ちます。割り込みを許可している場合は、カートリッジの割り込み出力もアクティブになります（第10章 10.4 参照）
- フラグは、対応するタイマーの割り込みが許可されているときにだけ立ちます。割り込みを許可していないと、オーバーフローしてもフラグは 0 のままです。そのため、割り込みを使わない場合でも、フラグをポーリングするには割り込み許可ビットを立てておく必要があります
- フラグはレジスタ 14h のフラグリセットビットでクリアします。クリアするまでフラグは立ったままで、割り込みも継続します

周期的な処理のタイミング源として使うほか、CSM モード（タイマー A のオーバーフローに同期してキーオンする機能）も YM2151 と同様に利用できます。

## 8.8 使い方

OPM で音を 1 つ鳴らすまでの手順は次のとおりです。

1. I/O イネーブラ（MMIO 7FFFh）の OPM ビットを 1 にして、OPM の I/O ポートを有効化する（第 3 章）。
2. チャンネル制御（20h〜27h）に、RL、FB、CON（アルゴリズム）を設定する。
3. KC／KF（28h〜37h）で音程を設定する。
4. 4 つのオペレータのパラメータ（40h〜FFh）を設定する。
5. キーオンレジスタ（08h）に、オペレータ指定とチャンネル番号を書いて発音を開始する。

音を止めるときは、08h にオペレータ指定を 0 にして同じチャンネル番号を書きます。書き込みキュー（8.3 節）があるため、手順 2〜4 の大量の書き込みも、BUSY を見ずに続けて行えます。

サンプル OPM801 は、Ch.1 に ALG0（4 オペレータ直列）の音色を設定して A4 を鳴らすプログラムです（ファイルはサンプル集に収録）。オペレータ 4 つ分の設定は同じ形の繰り返しになるため、ここでは M1 の分と発音開始までを引用します。

```
		; Ch.1 チャンネル制御 (20h): RL = 両方, FB = 4, CON = 0 (ALG0)
		ld		a, 20h
		ld		e, 0e0h
		call	opmw
		; Ch.1 KC (28h) = 4Ah (A4), KF (30h) = 0
		ld		a, 28h
		ld		e, 4ah
		call	opmw
		ld		a, 30h
		ld		e, 00h
		call	opmw

		;--- M1 (オフセット +0) ---
		ld		a, 40h			; DT1 = 0, MUL = 1
		ld		e, 01h
		call	opmw
		ld		a, 60h			; TL = 24
		ld		e, 18h
		call	opmw
		ld		a, 80h			; KS = 0, AR = 28
		ld		e, 1ch
		call	opmw
		ld		a, 0a0h			; D1R = 10
		ld		e, 0ah
		call	opmw
		ld		a, 0c0h			; DT2 = 0, D2R = 4
		ld		e, 04h
		call	opmw
		ld		a, 0e0h			; D1L = 6, RR = 6
		ld		e, 66h
		call	opmw
		…（M2 は +8、C1 は +16、C2 は +24 のアドレスで同様に設定）

		; キーオン (08h): 全オペレータ, チャンネル 0
		ld		a, 08h
		ld		e, 78h
		call	opmw
```

# 第9章 デジタルミキサー

本章では、Y8960 の全音源の出力をまとめるデジタルミキサーと、最終段の I2S 出力について説明します。

## 9.1 概要

Y8960 の音源ブロックはすべてステレオ化されており、その出力は FPGA 内部のデジタルミキサーで合算され、I2S インタフェースで DAC（PCM5102A）へ送られます。アナログ段でのミキシングは行われません。

ミキサーの入力は次の 5 系統です。

| 系統 | 内容 | ステレオ化の方式 | 詳細 |
|---|---|---|---|
| SSG | SSG × 2 コアの出力を加算したもの | チャンネルごとのパン | 第4章 |
| OPLL | OPLL-EX | チャンネルごとのパン | 第5章 |
| OPL2 | OPL2 と ADPCM を内部で加算したもの | チャンネルごとのパン（ADPCM も含む） | 第6章 |
| SCC | SCC 5 チャンネル | チャンネルごとのパン | 第7章 |
| OPM | OPM 8 チャンネル | チャンネルごとの RL ビット（左右出力指定） | 第8章 |

パン（ステレオ定位）の設定は各音源ブロック側で行います。ミキサー側の役割は、系統ごとの音量調整と合算、マスター音量の適用です。

なお、ADPCM には独立した系統音量はありません。ADPCM の音量は OPL2 系統の音量（9.2 節）に従います。

## 9.2 系統別ボリュームとマスターボリューム

音量レジスタはメモリーマップド I/O です（第3章 3.4 のウィンドウが開いているときに書き込めます）。すべて書き込み専用です。

| アドレス | 内容 |
|---|---|
| 7FF7h | SSG Volume |
| 7FF8h | OPLL Volume |
| 7FF9h | OPL2 Volume（ADPCM も含む） |
| 7FFAh | SCC Volume |
| 7FFDh | OPM Volume |
| 7FFEh | Master Volume |

各レジスタは 8 ビットで、値の意味は次のとおりです。

- 0 ＝ OFF（その系統は無音になります）
- 1～128 ＝ 音量。128 が最大です
- 129～255 を書いた場合は 128 と同じ（最大）として扱われます

リセット時の初期値は、全レジスタとも 128（最大）です。

ミキサー内部の処理は次の順序で行われます。

1. 各系統の入力に、その系統のボリュームを掛ける
2. 5 系統を合算し、24 ビットで飽和（サチュレーション）させる
3. 合算結果にマスターボリュームを掛けて出力する

## 9.3 飽和とクリップについて

合算は 24 ビットの飽和処理です。範囲を超えた値は最大値／最小値に張り付く（クリップする）ため、ラップアラウンドによる異常な音にはなりませんが、波形が潰れて歪みます。

合算後の減衰は行われません。系統ボリューム 128（×1）で 16 ビットフルスケールの音源を 1 系統だけ鳴らした場合でも出力は −6dBFS に達するため、複数系統を大きな音量で同時に鳴らすとクリップしやすくなります。

全系統を大きな音量で同時に鳴らすとクリップしやすくなります。歪みが気になる場合は、マスターボリュームではなく系統別ボリュームの側でバランスを取りながら下げると、各音源の相対バランスを保ちやすくなります。

## 9.4 I2S 出力

ミキサーの出力（24 ビットステレオ）は、I2S インタフェースで DAC へ送られます。

| 項目 | 仕様 |
|---|---|
| フォーマット | I2S（MSB ファースト） |
| スロット構成 | 32 ビット × 2 チャンネル。有効データは 24 ビット |
| BCLK | 約 6.04 MHz |
| LRCLK（サンプリング周波数） | 約 94.4 kHz（I2S クロック約 24.16 MHz を分周） |
| MCLK | 出力されません（DAC は MCLK なしで動作する設定です） |

プログラムから I2S を意識することは通常ありません。音量とパンに関する設定は、9.2 節のレジスタと各音源ブロックのレジスタで行います。

# 第10章 システム機能

本章では、音源ブロック以外のシステム機能――System Controller と MSX-TIMER――を説明し、あわせてリセット動作、割り込みの全体像、使用上の注意をまとめます。

## 10.1 System Controller

System Controller は、カートリッジの識別と、内蔵 Config ROM（SPI フラッシュ）へのアクセスを提供するブロックです。I/O ポート 40h～4Fh を使います。このポート範囲は音源ブロックの I/O イネーブラ（第3章 3.3）の対象外で、System Controller 独自の有効化手順を持ちます。

### 10.1.1 有効化とデバイスの識別

電源投入時、System Controller は無効状態であり、40h～4Fh の読み出しには応答しません。有効化と識別の手順は次のとおりです。

1. I/O 40h に 80h を書き込むと、System Controller が有効になる
2. 有効状態では、I/O 40h を読み出すと 7Fh（80h の全ビット反転）が返る。プログラムはこの値で System Controller の存在を確認できる
3. I/O 41h（デバイスセレクト）にデバイス ID を書き込む。自身の ID と一致したデバイスだけが、41h の読み出しに「ID の全ビット反転」で応答する（他のデバイスが応答する場合があるため、一致しないデバイスは応答しない設計になっている）
4. Y8960 Cartridge の ID は 02h である。41h に 02h を書いた後、41h を読み出して FDh が返れば、Y8960 の System Controller が選択されたことになる

デバイス ID の割り当ては次のとおりです。

| ID | デバイス |
|---|---|
| 00h | N/A |
| 01h | V9968 Cartridge |
| 02h | Y8960 Cartridge（本カートリッジ） |
| 03h | FPGA MSXtR CPU Board |
| 04h | FPGA MSXtR VDP Board |
| 05h | FPGA MSXtR SND Board |
| 06h～FEh | Reserved |
| FFh | N/A |

### 10.1.2 ファンクションセレクト

I/O 42h はファンクションセレクトです。System Controller が有効で、かつ 41h に 02h（自デバイス）が選択されているときに機能します。

| 42h への書き込み | 機能 |
|---|---|
| 01h | Config ROM Reader/Writer |
| その他 | N/A |

01h を書いた後に 42h を読み出すと FEh が返ります。01h 以外を書いた場合は FFh が返ります。System Controller が無効、または他デバイスが選択されている間は、42h の読み出しに応答しません。

### 10.1.3 Config ROM Reader/Writer

ファンクション 01h を選択すると、I/O 43h～47h が次のように割り当てられます。

| I/O | 意味 |
|---|---|
| 43h | アドレス最下位 8 ビット |
| 44h | アドレス中位 8 ビット |
| 45h | アドレス最上位 8 ビット |
| 46h | コマンド（読み出すと FFh） |
| 47h | データ |
| 48h～4Fh | Reserved（読み書きに応答しません） |

43h～45h で Config ROM のアドレス（24 ビット）を設定し、46h にコマンドを書き込むことで動作します。

| コマンド | 動作 |
|---|---|
| 00h | 読み出し。完了後、47h からデータを読める |
| 01h | 書き込み |
| 02h | セクター消去（64KB 単位。アドレス下位 16 ビットは無視される） |
| 03h | チップ消去 |
| 04h | ステータス読み出し。完了後、47h から Config ROM のステータスレジスタ 1 が読める（bit0 ＝ BUSY） |
| 05h～FFh | Reserved（無視される） |

書き込み／セクター消去／チップ消去は、コマンドを発行するだけです。完了は、ステータス読み出しを繰り返して BUSY ＝ 0 になったことで確認してください。

注意点として、コマンド実行中（数 µs）は System Controller が I/O アクセスを受け付けません（この間 /WAIT は出ません）。46h にコマンドを書いた後は、40h を読み続けて 7Fh が返るようになってから、次のアクセスを行ってください。

- 【要確認】バージョン表示レジスタ、ブートモードの設定機能、Config ROM の書き込みプロテクト機能については、現行の仕様資料および RTL では確認できませんでした。有無を確認中です。

### 10.1.4 起動時のブートコピー

電源投入時、System Controller は Config ROM の 7E0000h～7FFFFFh（128KB）を SerialSRAM の 00000h～1FFFFh へ自動的にコピーします。コピー中は他のモジュールが停止し、スロットの /WAIT 信号によって MSX 本体も停止します。したがって、MSX 側のプログラムが動き出す時点ではコピーは完了しており、プログラム側で待つ必要はありません。

この仕組みにより、カートリッジのプログラム／データは電源投入直後から SerialSRAM 上に配置され、SCC バンク（第3章 3.5）経由で実行・参照できるようになります。

## 10.2 MSX-TIMER

MSX-TIMER は、独立したタイマーコアを 4 個内蔵するブロックです。周期割り込みの発生や、経過時間の計測に使えます。

### 10.2.1 ポートとアクセス方法

I/O ポート B0h～B3h を使います。電源投入時は無効なので、あらかじめ I/O Enabler2 の TIMER ビット（bit7）を 1 にして有効化してください（第3章 3.3 参照）。

| ポート | 読み出し | 書き込み |
|---|---|---|
| B0h | インデックス（現在の値） | インデックスの設定 |
| B1h | インデックスが指すレジスタの値 | インデックスが指すレジスタへの値の設定 |
| B2h | 割り込みフラグ（bit3～0 がコア 3～0 に対応、上位 4 ビットは 0） | フラグクリア（bit3～0 に 1 を書くと対応するコアのフラグがクリアされる） |
| B3h | 選択中コアの現在のカウント値 | カウンタ読み出し対象のコア選択（値 0～3） |

インデックスの形式は次のとおりです。

| ビット | 意味 |
|---|---|
| bit3～2 | コア番号（0～3） |
| bit1～0 | コア内レジスタ番号（0～2、次節） |

![B0h（インデックス）のビット配置](images/bf_timer_index.png)

![B2h（割り込みフラグ）のビット配置](images/bf_timer_flag.png)

B3h のコア選択で 0～3 以外の値（bit7～2 のいずれかが 1 の値）を書いた場合、B3h の読み出しは FFh を返します。

レジスタの読み出し（B1h）には内部処理のために数サイクルを要し、その間はハードウェアがウェイトを挿入します。プログラム側で特別な待ち処理は不要です。

### 10.2.2 コア内レジスタ

各タイマーコアは次のレジスタを持ちます。

| レジスタ番号 | 名称 | 内容 |
|---|---|---|
| 0 | モードレジスタ | bit7：割り込み許可、bit6～4：分解能（RESO）、bit0：リピート |
| 1 | カウントレジスタ | タイムアップまでのカウント値（8 ビット） |
| 2 | コントロールレジスタ | bit0：カウント許可、bit1：カウンタクリア（1 を書くとカウンタが 0 に戻る） |
| 3 | － | 未実装（読み出しは 00h） |

![モードレジスタのビット配置](images/bf_timer_mode.png)

![コントロールレジスタのビット配置](images/bf_timer_ctrl.png)

モードレジスタとカウントレジスタ、コントロールレジスタはいずれも読み戻しが可能です。

### 10.2.3 動作

- コントロールレジスタの bit0 を 1 にするとカウントを開始します
- RESO はプリスケーラの選択で、1 カウントの単位時間を決めます。カウンタは内部で広いビット幅を持ち、RESO によって比較に使う範囲が切り替わるため、単位時間は RESO が 1 上がるごとに 4 倍になります
- カウント値がカウントレジスタの値に達するとタイムアップとなり、割り込みフラグが立ちます
- リピート（モードレジスタ bit0）が 0 の場合はワンショットで、タイムアップと同時にカウントが停止します。1 の場合はカウンタが自動的に 0 に戻り、カウントを繰り返します
- 割り込みフラグは、割り込み許可の有無にかかわらず立ちます。フラグは B2h への書き込みで明示的にクリアするまで保持されます。割り込み許可が 1 の間、フラグが立っているコアがあるとカートリッジの割り込み出力がアクティブになります（10.4 節）
- 現在のカウント値は B3h で読み出せます（10.2.1 参照）

単位時間は、コアのクロックを f とすると 2^(10 ＋ 2×RESO) ÷ f です。タイムアップまでの時間はおおよそ（カウント値 ＋ 1）× 単位時間になります。下表は f ＝ 42.95454 MHz として計算した参考値です。

| RESO | 単位時間（参考） | カウント値 255 のときの周期（参考） |
|---|---|---|
| 0 | 約 23.8 µs | 約 6.1 ms |
| 1 | 約 95.4 µs | 約 24 ms |
| 2 | 約 382 µs | 約 98 ms |
| 3 | 約 1.53 ms | 約 391 ms |
| 4 | 約 6.10 ms | 約 1.56 s |
| 5 | 約 24.4 ms | 約 6.25 s |
| 6 | 約 97.7 ms | 約 25 s |
| 7 | 約 391 ms | 約 100 s |

- タイマーのベースクロックは 42.95454 MHz で、上表はこのクロックで計算した値です。

### 10.2.4 使用手順の例

コア 0 を周期タイマーとして使う場合の流れです。

1. I/O Enabler2 の TIMER ビットを有効化する
2. B0h に 00h（コア 0、モードレジスタ）を書き、B1h にモード（割り込み許可、RESO、リピート）を書く
3. B0h に 01h（コア 0、カウントレジスタ）を書き、B1h にカウント値を書く
4. B0h に 02h（コア 0、コントロールレジスタ）を書き、B1h に 03h（カウンタクリア＋カウント許可）を書く
5. 割り込みハンドラでは B2h を読んでフラグを確認し、処理したコアのビットに 1 を書いてフラグをクリアする

## 10.3 リセット動作

電源投入時およびリセット時の各ブロックの状態は次のとおりです。

| 対象 | リセット時の状態 |
|---|---|
| 音源ブロックの I/O ポート（SSG／OPLL／OPL2／OPM／MSX-TIMER） | すべて無効（I/O Enabler1／2 が全 0）。アクセスしても応答しない |
| ミキサーのボリューム（系統別・マスター） | すべて 128（最大） |
| SCC バンクレジスタ | BANK0～BANK3 に BANK#0～#3、RAM モード ＝ 0 |
| SCC ステレオ定位 | 全チャンネル 128（中央） |
| SCC 出力スイッチ | 全チャンネル オフ |
| OPM 書き込みキュー | 空（BUSY はやがて 0 になる） |
| MSX-TIMER | 全コア停止、割り込みフラグ クリア、割り込み許可 0 |
| System Controller | 無効（使用時に 10.1.1 の手順で有効化する） |
| Config ROM → SerialSRAM のブートコピー | 電源投入時に実行される（10.1.4 参照） |

I/O ポートが無効の間は音源チップへアクセスできないため、実質的に音は出ません。推奨する初期化の流れは次のとおりです。

1. 使用する音源の I/O ポートを I/O Enabler1／2 で有効化する
2. 各音源チップのレジスタを初期化し、音色・音量を設定する
3. 必要に応じて、ミキサーの系統別ボリュームと各チャンネルのパンを設定する
4. タイマーや割り込みを使う場合は、最後にそれらを設定・許可する

- 【要確認】MSX 本体のリセット時に、ブートコピーが再実行されるか、System Controller の有効状態がどうなるかは確認中です。

## 10.4 割り込み

Y8960 がカートリッジの割り込み出力（/INT）をアクティブにする要因は、次の 3 系統です。

| 要因 | 発生条件 | フラグの確認とクリア |
|---|---|---|
| MSX-TIMER | いずれかのコアがタイムアップし、割り込みが許可されている | B2h で確認し、B2h への書き込みでクリア（10.2 節） |
| OPL2 内蔵タイマー | タイマー A／B のオーバーフロー（割り込み許可時） | OPL2 のステータスレジスタで確認し、リセットビットでクリア（第6章） |
| OPM 内蔵タイマー | タイマー A／B のオーバーフロー（割り込み許可時） | ステータスレジスタ（7Fh 読み出し）で確認し、レジスタ 14h でクリア（第8章） |

3 系統の割り込み出力は内部で合成されてスロットの /INT に出ます。/INT は要因が 1 つでも残っている間アクティブなままです。割り込みハンドラでは 3 系統すべてのフラグを確認し、発生したものをすべてクリアしてから復帰してください。クリアし忘れた要因があると、復帰直後に再び割り込みがかかります。

SSG、OPLL、SCC には割り込み出力はありません。

## 10.5 使用上の注意

- **I/O アドレスの競合**: Y8960 の音源ポートは、電源投入時はすべて無効になっています。これは、他のカートリッジや MSX 本体のデバイスとアドレスが重なっても競合しないようにするための仕様です。使用するポートだけを有効化してください。特に SSG の A0h～A3h は MSX 本体内蔵 PSG と同じアドレス範囲であり、有効化すると内蔵 PSG と同時に書き込まれる点に注意してください（第4章参照）
- **メモリーマップド I/O の有効条件**: ボリュームや I/O イネーブラなどのメモリーマップド I/O（7FF0h～7FFFh）は、RAM モードと BANK1 の状態によってはウィンドウが閉じてアクセスできない場合があります（第3章 3.4 参照）。設定が反映されない場合は、ウィンドウの状態を確認してください
- **OPM の連続書き込み**: OPM は書き込みキューと /WAIT により取りこぼしを防ぎますが、大量のレジスタ書き換えを短時間に行うと CPU が待たされ、演奏処理などが遅れる場合があります（第8章 8.3 参照）
- **Config ROM の書き換え**: Config ROM Reader/Writer はカートリッジの保守・更新のための機能です。通常の演奏プログラムからは使用しないでください。消去は 64KB セクター単位またはチップ全体であり、誤った操作はカートリッジの起動に必要なデータを失わせます
- **SCC のアクセス禁止領域**: SCC レジスタバンク内の未使用領域（98A0h～98DFh、9905h～9FFFh など）はアクセス禁止です（第7章 7.3 参照）
- **高速な連続アクセス**: 高速ループでの連続アクセスは、バスの占有により音切れの原因となる場合があります。レジスタ書き換えは必要最小限にとどめることを推奨します
